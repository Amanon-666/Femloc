# 第一版完成核验与方法判断

## 完成情况

训练代码提交 `88ad290`。开发训练八次：Meta 三个 λ × 两种子、Sup 两种子，每次 2000 源更新；不是让目标适应 2000 步。最终各三种子训练 Meta 1000 步、Sup 250 步。每个种子十源楼层，三个目标、五组 Support，六方法，三类指标，共 **45 个任务组合、810 条指标记录**。根与各阶段完成标志齐备，全部误差有限，训练进程已退出。

实际检查验证了双/原形式等价、梯度、坐标平移、逐条/整批 Query 一致、源/目标按位置隔离与真实源网络单步训练。开发所有方法相同种子的完整 2000 步采样摘要一致。最终模型源层清单排除了三个目标，实际源更新步数与各自历史选择一致。固定最终 manifest 的全部 Support 为 10 个位置、每位置 3 扫描；全部异位置 Query 与其位置不重叠。

核验原始数据：`docs/RIDGE_REFERENCE_AUDIT.json`；冻结选择：`docs/RIDGE_REFERENCE_SELECTION.json`；完整配对汇总：`docs/RIDGE_REFERENCE_SUMMARY.json`。逐行预测指标、权重和 manifest 留在服务器 `outputs/ridge_reference_v1/`，不把大批输出并入代码。

## 实验支持了什么

官方 validation 建筑等权 MDE：Meta 16.94m，Sup 18.87m，随机特征 22.82m，原始 RSSI 岭回归 21.25m，只用 Support 的 WKNN 20.13m，完整相邻楼层旧地图 11.44m。

同日未标定位置：Meta 13.89m，Sup 14.62m，随机特征 19.87m，原始 RSSI 岭回归 18.51m，Support-WKNN 18.39m，旧图 10.38m。

因此少量标定专门训练表征有收益，但相对公平普通监督对照的增益较小，而且不统一：B2F4 同日 Meta 比 Sup 差 0.24m；官方验证 Meta 21.35m，随机特征 21.66m，原始 RSSI 岭回归反而 20.69m。不能宣称每个新楼层都受益，也不能宣称打败强地图方法。

目标端 Meta 的 Support 特征提取加 30×30 求解耗时中位数约 0.293ms，表征冻结、无目标梯度更新。快速适应的计算机制已成立，但好的速度不自动代表足够好的定位精度。

## 主动排除的解释

### 1. 不是简单再加源训练轮数

λ=.1 下历史整层留出 MDE：

|源更新数|Meta (m)|Sup (m)|
|---:|---:|---:|
|0|23.940|23.940|
|250|15.890|16.227|
|500|15.996|16.618|
|1000|15.757|16.567|
|2000|15.974|16.312|

主要学习收益在 250 次源更新以内形成，继续到 2000 没有持续改善。这个有限预算不能证明所有训练策略都已穷尽，但不支持“仅因为训练不足，所以继续堆更新数”作为下一轮首选解释。

### 2. 标定点拟合更小，不保证未知位置更小

Meta 的 Support MDE 为 5.36m，随机特征 4.56m、原始 RSSI 4.04m；但后两者的同日未知位置误差更大。Support-WKNN 近乎直接记住标定扫描（0.53m），未知位置却达 18.39m。正则化模型没有把训练点拟合到零，本身不能据此判断训练坏了；本任务检验的是少数标定点之外的空间定位。此对照提供了实际证据，不需靠网络更复杂来推断。

### 3. B2F4 官方验证确有输入和几何覆盖变化

五组 Support 平均后的描述性统计：

|B2F4 评价|同日未知位置|官方 validation|
|---|---:|---:|
|每扫描可见 AP 数的中位数|19|12|
|Query 可见 AP 观测中未在 Support 出现的比例|6.65%|13.08%|
|Query 可见 AP 观测中未在全部十源层出现的比例|0.40%|6.00%|
|到最近 Support 坐标的平均距离|9.05m|14.71m|

官方 B2F4 仅 39 条扫描。这些统计说明信号可见性与锚点覆盖同时变化；不能用它们单独证明设备效应、时间效应或某一个模型模块的因果责任。B0 的验证同样有源层未出现 AP，因此“有新 AP”不是解释 B2 失败的充分条件。

固定表征训练只能从十源层获得特征权重；目标端 Support 改变的是坐标解及归一化统计，没有重新学习目标的 AP 关系。B2 的结果限制了这种机制当前的适用范围。这是下一种 Support 条件表征假设的依据，尚不等于该假设已经被验证。

### 4. 完整旧图的优势是真实部署信息优势

旧图保留了相邻楼层的密集位置、信号和绝对坐标，可以直接检索。Meta 目标侧仅有十个坐标锚点，历史空间知识主要保存在共享特征参数中。旧图强不能被忽略，也不能把额外几何信息完全归功于算法更简单。部署已有空间对齐旧图时，本版训练方法暂时没有取代它的证据；部署没有可复用坐标图时，两者解决的可用信息条件不同。

## 后续方法路线

主线仍保持可微 Support 求解。下一轮可独立研究“Support 是否需要先校准表征或相似度，再求坐标”，而不是新增目标梯度循环或在现有求解后叠加误差补偿。设计时必须解释：校准由哪些目标可观察统计驱动、为何能处理 AP 可见集合和相似关系变化、对 Query 可否独立预测，以及普通监督表征能否得到同样收益。先在历史留出层形成判断，不能按 B2F4 最终误差挑规则。

本轮没有实施这种新组件，没有新增 K 曲线，也没有声称已经证明减少多少位置可以维持某一精度。当前的价值是提供了一条数学和数据权限明确、对照公平、真实跑完的主线参考。
