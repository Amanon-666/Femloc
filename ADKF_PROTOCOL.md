# ADKF-IFT UJI adaptation, 2026-10-13, before formal experiment

Question: does target GP refitting explain the improvement, and does exact bilevel feature learning add beyond refitting? This is a position-isolated cross-building experiment, not a temporal map-maintenance experiment.

Author method: https://arxiv.org/html/2205.02708v5; official https://github.com/Wenlin-Chen/ADKF-IFT commit b82497e1382e4edd821d1c6132d080035b456884. The author cauchy_hypergradient_jvp.py is copied unchanged, MIT license included. Molecule encoder is replaced by the existing UJI 520→40→40 ReLU encoder. Two independent coordinate outputs use scaled RBF GPs.

All methods use fixed RSS encoding (100→0, otherwise (RSS+105)/105), Support coordinate center, and coordinate scale estimated only from the other buildings. ZeroMean is shared by all methods, so these numbers will not reproduce earlier ConstantMean DKT. Amplitude, isotropic lengthscale and coordinate-residual noise are GP parameters.

Methods: raw_source (shared GP joint-MLL trained on source tasks, frozen at target); raw_refit (raw RSS GP fit only on Support); dkt (deep feature+shared GP trained by joint source MLL, all parameters frozen at target); dkt_refit (exact same selected dkt network, only GP reset/refit on target Support); adkf_ift (source Support fit GP; source Query joint conditional NLL trains features with exact implicit hypergradient; target feature frozen, GP reset/refit).

Refit/ADKF inner initialization: amplitude=1, lengthscale=sqrt(0.5 median positive squared Support-feature distance), noise=.01. LogNormal noise prior std=.25, mode=.01; lengthscale prior std=.25 with mode equal to initial median. Noise and lengthscale priors follow the author implementation. UJI adaptation adds a proper LogNormal signal-variance prior, mode=1, std=1, shared by every refit method. Source RMS normalization and rotation imply typical per-axis variance=1; std=1 is an a priori weak prior, never target-selected. The added signal prior prevents the ML zero-amplitude boundary in constant/very-low-variance coordinate axes, where unregularized IFT becomes singular. The prior context is detached and kept fixed within each inner optimum and its IFT derivative, as in author's code. Noise is a coordinate regression residual variance, not an RSS measurement noise. With source scale ≈33m, prior noise SD ≈3.3m. Frozen joint-MLL methods do not receive these per-task fitting priors; consequently the dkt vs dkt_refit difference measures the regularized adaptation procedure. The dkt_refit vs adkf difference shares identical target adaptation, isolating the feature training strategy better.

LOBO: all learning, coordinate scale, source development selection exclude the held building. Highest source floor per remaining building is held out for source development. Checkpoints 300/1000 steps, 2 seeds (0,1), one source episode per step, source K uniformly from 3/5/10/20, 3 unique scans per Support position, 30 separate Query positions with one scan each. Rotation/reflection labels augment source episodes. Source-dev MDE averaged across internal and official source queries selects steps independently per method. Refit chosen schedules on all allowed sources, and retain checkpoints. No target metric selects anything.

Target: fixed 30% physical Query positions from trainingData, remaining positions provide nested K=3/5/10/20 Support; 10 fixed draws with 3 unique scans per Support point. Official validation Query excludes coordinates present in the maximum-K Support of each draw, using the same Query rows for every K and method in that draw. All methods share row-ID manifest. Both splits report MDE and nominal 90% elliptical coverage.

Reverse audit: target output is Support center + source coordinate scale × GP conditional mean; no Query coordinate is passed to model. Every adaptive prediction recomputes fresh 3-parameter GPs independently per axis; feature output is no_grad/detached before inner optimization. Source outer loss uses dense Schur complement joint covariance, including feature gradients through Support; it has no detached GP caches. IFT differentiates the same prior-containing Support loss that scipy minimizes. Inner L-BFGS-B maxiter=100 and stationarity recorded; target prediction raises on fit gradient >1e-4 rather than reporting it as converged; formal source update raises on gradient >1e-4 or Hessian eigenvalue ≤1e-8 rather than using pseudoinverse.

Limits/counterexamples: empty/one-point Support does not identify coordinate structure, and is outside the K≥3 experiment. Repeated scans do not equal distinct locations. Collinear Support with a constant coordinate can drive amplitude toward zero without the added signal prior and cannot establish spread in that direction; target fit diagnostics remain visible. Completely collapsed feature distances make median initialization undefined and are an explicit error. Unknown AP columns have no trained semantics; cross-building encoder can fail, and target GP refitting cannot restore lost features. Separate 2-axis GPs are not rotation-invariant uncertainty models. Source floors are few physical domains even though many episodes are sampled; no claim of matching the source diversity of FS-Mol. Full Query NLL is joint, not a sum of marginal pointwise NLLs.

CPU only, 2 Torch/BLAS threads, no interruption of existing GPU jobs. Preflight is source-only mathematical verification (finite differences, stationarity, Hessian), not a performance experiment. Frozen code hash, manifests, source checkpoints and actual results are saved under outputs/adkf_lobo.

Chronology: initial source-only random tasks passed, but parent independently identified constant-output amplitude boundary before formal training. A direct source-coordinate counterexample showed amplitude≈2.5e-11 and Hessian eigenvalue≈1.65e-9, despite scipy convergence. Proper signal prior was therefore added before freezing/formal experiments; no target scores were used. Original source preflight files are preserved separately.
