# 冻结旧网络后直接求目标楼层的小型映射

本诊断使用 `metaloc-few-shot` 提交 `ab13e65` 保存的 MI/TL 网络和原来的三组 `10 位置×3 扫描` Support 划分。网络权重完全冻结。只取倒数第二层特征，在 Support 内按位置整组留一选择岭回归强度，再对原异位置 Query 预测。没有用 Query 坐标拟合映射或选强度，也没有重新训练模型。完整 18 行记录见 `evidence/frozen_head_diagnostic.json`；脚本为 `scripts/diagnose_frozen_head.py`。

下表为三个原任务种子的扫描等权平均二维误差，单位是 UJI 原始投影坐标。`整体平移` 是先用 Support 算原网络的平均预测偏差，统一加回 Query；`岭回归` 是直接用 Support 求一个 128 维特征到相对坐标的小型映射。WKNN 使用本分支固定 RSSI 归一化后的三近邻，与其他项目可能采用的信号距离定义不同。

|目标|旧特征|整体平移|冻结特征＋岭回归|WKNN|
|---|---|---:|---:|---:|
|B0F3|TL|10.31|9.97|13.10|
|B0F3|MI|9.47|10.65|13.10|
|B1F3|TL|23.92|20.71|32.95|
|B1F3|MI|24.12|19.61|32.95|
|B2F4|TL|21.70|13.09|12.52|
|B2F4|MI|21.58|12.24|12.52|

结果支持一个限定判断：原先 10 步梯度更新缓慢，至少部分是**目标端怎样用少量样本**的问题；旧特征在部分楼层已允许更快的映射。B0F3 的 MI 反例说明直接岭回归也不是通用改进。B1F3 三个种子的 WKNN 差异很大，均值尤其不能代替逐任务配对分析。这三层已被反复查看，因此本诊断只形成训练方法的假设，不是新算法确认成绩。

下一版方法把“源训练特征→用 Support 求映射→只考未见位置”放在**同一个训练目标**里；它要超过原始 RSSI＋岭回归、随机特征＋岭回归和 WKNN，才能证明源端学到的表示有额外价值。
