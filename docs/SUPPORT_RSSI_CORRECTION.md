# 少量目标锚点应在无线观测空间提供信息

旧地图软匹配已接近三个目标楼层的论文表格数值，但源预测坐标空间中的局部残差在 B1F3 反而变差。源模型可能把不同 RSSI 扫描压到相近的坐标，故“预测坐标相近”不一定表示残差相似。若 10 个目标位置有帮助，最直接的机制是：无线扫描与某目标锚点相似时，借用该锚点上观测到的旧地图定位偏差。

对每个 support 位置将 3 条归一化 RSSI 取平均 `s_i`，将旧地图预测坐标取平均 `m_i`，残差 `r_i=y_i-m_i`。对于 query RSSI `x`，预测为 `m(x)+k(x,S)(K(S,S)+lambda I)^(-1)r`，其中 `k(x,s)=exp(-gamma*||x-s||²)`。`gamma` 候选 `{2,5,10,20}`，`lambda` 候选 `{0.3,1,3}`，另有“不校正”。仅在七对旧楼层转移、每对 20 个模拟 10×3 episode 上选择，转移等权；目标 Query 不参与。它是对十个锚点的闭式更新，无目标梯度，且直接作用于无线相似性，和此前的预测坐标核是不同的可解释假设。

这个单独实验与相邻楼层软地图共享同一 beta 和目标 manifest。若源端选择不校正，或目标端仍无稳定收益，则不继续增加门控和楼层特例；说明这 10 个目标位置在当前输入权限和选点方式下不足以稳定修正跨楼层指纹图。
