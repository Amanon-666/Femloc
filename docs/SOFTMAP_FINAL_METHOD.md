# 第一版保留的简单方法：相邻楼层软指纹地图

整对楼层留出验证显示，针对七对旧楼层学 520 个 AP 权重会降低新楼层转移表现，最优源训练长度为 0。故把已无证据支持的 AP 权重训练从最终推理路径删去，只保留各 AP 等权的软匹配。

对旧楼层每个坐标位置的全部扫描取平均指纹 `u_p`。目标扫描 `x` 与每个旧位置的距离是归一化 520 维 RSSI 平方差 `d(x,u_p)`。预测坐标 `m(x)=sum_p softmax_p(-beta*d(x,u_p))*p`。`beta` 只能从七对旧楼层转移上的候选 `{1,2,5,10,20,50,100}` 按等权平均误差选，目标 Query 不参与。这个输出不需要目标标注，属于相邻楼层地图迁移基线。

为了检验少样本价值，保持十位置×三扫描的固定目标 manifest，另报告同一 source-only 标定规则选择的局部残差校正。它确实读取 30 条目标标注，却没有目标梯度更新。比较“有/无锚点”的配对结果，不把旧地图本身的高准确率归功于 few-shot。目标梯度步为 0，满足不超过 50 步，但不等同于 FeMLoc 的快速梯度适应。

本方法只适用于同建筑有完整相邻旧楼层 radio map 的情况。若目标下方无旧地图、建筑间 AP 不重叠或楼层平面布局不同，需要另一种方法。本轮 B0F3/B1F3/B2F4 在探索阶段已被多次查看，数值不是外部盲测。FeMLoc 原文报告的 5.1/13.1/12.2 米是 100 次目标更新后的结果；论文未明确提供与这里相同的 30 标注、位置隔离 Query 和完整相邻旧地图权限，因此仅作数值参照。
