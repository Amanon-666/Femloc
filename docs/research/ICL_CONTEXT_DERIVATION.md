# 迁移先验作为上下文：TPM 生成式先验 + 表格基础模型（实验前推导）

日期：2026-09-30。起点 `ab1a60b`（TPM 主线），分支 `tpm-icl-context`。本文件在实现与任何成绩之前提交。

## 1. 问题与动机

TPM 的四步中，第 2 步（跨楼层先验）是从源楼层对学出来的；第 3、4 步（锚点 GP 校正、Tobit 匹配）是手工推导的规则。前沿的少样本回归把"如何利用少量样本"交给预训练的上下文学习模型：TabPFN（Hollmann 等，Nature 2025）把上下文预测解释为对先验下后验预测的近似；TabICLv2（arXiv 2602.11139，官方实现 soda-inria/tabicl）直接接收数值特征与少量训练行；RA-LWLM（arXiv 2606.01899，尚未同行评审）把场景信息存入外部库，以"检索 + 上下文学习"免训练适应新场景。

本轮只问一个问题：**把 TPM 的跨楼层先验以样本形式放进上下文模型，能否替代手工的锚点校正与匹配？**

## 2. 可用信息与数据权限

与 TPM 主线完全一致：目标层只读 K 个位置×3 条带坐标扫描；相邻旧楼层的完整 trainingData；跨楼层先验按留一楼层只用不含目标层的楼层对拟合。TabICL 的预训练只用合成表格数据，未见过 UJI。官方 validation 与同日异位置 trainingData Query 只用于评价。**本轮没有任何参数按成绩选择**：所有设计常数在本文件中预先固定。

## 3. 推导

### 3.1 上下文应当是什么样本

上下文学习模型从上下文行 (x_i, y_i) 学习 y 关于 x 的条件关系，再对查询扫描作预测。若上下文行与查询行来自同一联合分布，模型面对的就是它预训练时的标准任务。查询是**单次扫描**（每个 AP 可能被检出、也可能未报告），所以上下文行也应是单次扫描，而不是地图均值：用均值行训练、用带噪扫描测试，是输入误差下的回归，会产生衰减偏差。

TPM 的先验恰好是一个生成模型。对旧层坐标 p_j、AP a，它给出潜在水平 ℓ 的先验 N(μ_ja, v_ja)，以及观测模型：检出 ~ Bernoulli(h·Φ((ℓ−θ)/s))，检出值 ~ N(ℓ, σ_t²)。因此可以精确采样**先验预测分布下的单次扫描**：

```
ℓ ~ N(μ_ja, v_ja)           每条扫描、每个 AP 独立抽取
检出 ~ Bernoulli(h·Φ((ℓ−θ)/s))
检出值 = round(ℓ + σ_t·ε)，裁剪到 [−104, 0]；未检出记 UJI 编码 100
```

每条扫描独立抽 ℓ，得到的是对潜在不确定性积分后的边缘预测分布 p(x | y=p_j)。先验把握小的 AP 在合成扫描里波动更大，上下文模型会自然降低对它们的依赖；不需要另设 AP 权重。TPM 使用的地图 E[x_imp] 正是这个分布在插补编码下的均值，所以合成上下文与 TPM 用的是同一个先验。

### 3.2 两类行怎样共存

合成行是先验的近似，存在系统偏差（TPM 零标注 14.50 m，完整目标图 8.12 m）；锚点行是目标层的真实扫描。给每行加一列来源标记 t（合成 0、锚点 1），查询标记为 1。这是多源表格学习中常用的域指示特征：上下文模型可以学到"标记 1 的行与查询更相似"，让锚点在其附近主导，而不是被数量多得多的合成行淹没。标记列作为主方法的一部分预先确定，另报告去掉它的消融。

### 3.3 预先固定的设计常数（不调）

| 选择 | 取值 | 依据 |
|---|---|---|
| 每个旧层坐标的合成扫描数 r | 3 | 与锚点每位置 3 条扫描相同：每个位置无论真假，在上下文中权重相同 |
| 特征编码 | 检出 (x+105)/105，未报告 0 | 沿用 RNP-UJI 的 TabICLv2 基线；未报告取最低值而非缺失，保留"未检出带信息"这一已验证事实 |
| 特征列 | 旧层或锚点中出现过的 AP，再去掉在上下文中恒定的列 | 恒定列对上下文回归不含信息 |
| 坐标 | 减去旧层坐标均值，x、y 两轴分别回归 | TabICL 回归器为单输出；与 RNP-UJI 相同 |
| TabICL | tabicl==2.2.0、回归权重 v2-20260212、默认 8 个视图、官方 predict() | 与 RNP-UJI 锁定版本一致 |

### 3.4 可证伪的预测

- **H1**：先验上下文有用。ICL(先验+锚点) 优于 ICL(仅锚点)，锚点越少差距越大。
- **H2**：学到的迁移先验在上下文中仍有价值。ICL(先验+锚点) 优于 ICL(旧层原始扫描+锚点)。后者用旧层真实扫描（每位置 3 条）替代合成扫描，其余相同，对应"检索场景库"的做法。
- **H3**：开放问题。ICL(先验+锚点) 与 TPM（锚点 GP + Tobit）相比。若 ICL 更好，主线改为"迁移先验作合成上下文"；若更差，说明手工推导的校正和匹配对这类稀疏 RSSI 已接近上下文模型的能力，TPM 保留为主线，ICL 结果作为前沿对照写入。
- **H4**：零标注。ICL(仅先验) 与 TPM 零标注先验地图 + Tobit（14.50 m）相比。

## 4. 已知风险（开跑前写明）

1. 检出链接在高端偏高约 0.1（后验预测检验），合成扫描的检出率会系统偏高；来源标记只能部分吸收。
2. 合成检出值是高斯加取整，真实分布可能偏斜；不作修正。
3. 输出不受候选坐标凸包限制，可外推；这可能改善 B2F4 类覆盖问题，也可能产生离谱预测。
4. 两轴独立回归，忽略坐标的联合结构。
5. 合成行数（约 210–340）远多于锚点（30）；标记列能否让模型区分，只能由实验回答。

## 5. 冻结协议

- 历史 7 层，先验留一楼层；K=10 用与 TPM 相同的 20 个 episode（`episodes(..., 10, 20, 3, rng=1001)`）；K 曲线 {3,5,10,20} 用同一随机流（rng=2001），与 TPM 结果逐 episode 配对。
- 每个 episode 同一次拟合同时预测官方 validation 与同日异位置 Query。合成采样与 TabICL 的随机种子由 (楼层, K, episode) 确定。
- K=10 方法：TPM；ICL 仅锚点；ICL 仅先验；ICL 先验+锚点；ICL 先验+锚点（无标记）；ICL 旧层扫描+锚点。K 曲线：TPM、ICL 仅锚点、ICL 先验+锚点、ICL 旧层扫描+锚点。
- 附录：FeMLoc 三目标层，先验用全部 7 对，3 组固定 manifest；探索性。
- 结果无论方向如何都完整报告；不按结果增删变体或改常数。
