## 当前决策

保留两个互补参照：TrGP 是直接使用 UJI 的权威迁移回归基线；MetaLoc 至 AGML 是任务适应与关系学习的研究链。近期 RSSI 性能对照仍包括 UE-GLoc。不能为了作者代码易拿就回到已经试过的 DKT，也不能因为 TrGP 使用 GP 就把它等同于 TPM 的空间残差校准。

复现准备优先级为：先厘清 TrGP 的条件训练目标、输出尺度和数据划分，同时审查 MetaLoc 作者实现；AGML 用于界定近期研究问题与额外数据条件，暂不把 CSI/CIR 加数字孪生方案直接改名为 UJI 复现。尚没有证据选定一个新的主模型，更没有证据证明 TPM 已达到外部先进水平。

## TrGP 方法卡

原文：Wei et al., *Adaptive Transfer Kernel Learning for Transfer Gaussian Process Regression*, TPAMI 45(6), 7142–7156, 2023，DOI [10.1109/TPAMI.2022.3219121](https://doi.org/10.1109/TPAMI.2022.3219121)。核对作者稿 §3.4、§4、§5、§6.3，原文缓存 `/Users/Admin/Zotero/storage/PI77KA5X/.zotero-ft-cache`。

论文学习 RSSI 输入上的域内、域间协方差，并由源标签条件化目标标签；不只是调节坐标空间上的残差平滑程度。UJI 设置为一个源建筑的1000条训练记录、另一个目标建筑25条训练记录和1000条测试记录。表4的 RMSE 0.0963 不能解释为米；本轮没有确认坐标变换、输出维数及采样索引。尚未找到可核验的作者代码。后续自行实现须称“按论文机制复现”，不能称作者实现或原数值精确复现。

下面是为实现复核而独立重写的推导，结论属于既有迁移 GP 理论，不是我们的新理论。令 RSSI 向量为 x，域标识 d∈{s,t}，每个基础核 k_r 为 PSD。取

\[
B_r=\begin{pmatrix}a_r&b_r\\b_r&a_r\end{pmatrix},\qquad
k((x,d),(x',d'))=\sum_r B_r[d,d']k_r(x,x').
\]

B_r 的两个特征值是 a_r+b_r 与 a_r−b_r，因此 a_r≥|b_r| 保证 B_r PSD。对任意一批带域标识的样本，令 Z 为域的 one-hot 矩阵，则每项 Gram 矩阵为 (ZB_rZᵀ)⊙K_r；由 Schur 乘积定理及 PSD 加法封闭性，完整迁移核有效。这说明约束保证的是**联合的跨域协方差**。只证明我们旧空间核 PSD，回答不了这个跨域问题。这里给出充分性；不把固定的一组基础核下的充分条件擅自说成所有情况下的必要条件。

设历史标注为 D_s=(X_s,y_s)，目标 Support 为 S=(X_t,y_t)。以下公式针对一个坐标轴、已明确均值处理的零均值模型；另一个坐标轴如何共享参数须单独冻结。把观测噪声写进协方差块：

\[
A=K_{ss}+\sigma_s^2I,\quad B=K_{st},\quad
D=K_{tt}+\sigma_t^2I.
\]

高斯条件分布给出

\[
y_t\mid D_s,X_t\sim\mathcal N(m,V),\quad
m=B^\top A^{-1}y_s,\quad V=D-B^\top A^{-1}B.
\]

训练最小化

\[
\mathcal L_{\mathrm{cond}}=
\tfrac12(y_t-m)^\top V^{-1}(y_t-m)
+\tfrac12\log|V|+\tfrac{n_t}{2}\log(2\pi).
\]

**实际代码必须检查的区别：**论文 §3.4 和 §4.3 使用目标条件似然。若把全部源、目标记录直接放进普通 GP 的联合边际似然，优化的是

\[
-\log p_\theta(y_s,y_t)
=\mathcal L_{\mathrm{cond}}-\log p_\theta(y_s),
\]

额外项一般依赖 θ，因此不是等价实现。只有该额外项对本次优化参数为常数时，两个目标才给出相同梯度。源记录远多于目标记录时，额外源拟合目标尤其不能无声加入。

推理时对目标新扫描 x_* 形成与源和 Support 的交叉协方差，条件化两者的标签。Query 标签不在模型接口内；Query 特征不参与超参数拟合。论文方法允许通过目标 Support 拟合核参数，因此不能把它包装成“测试时零次优化”的快速适应。要分别报告标注预算、目标优化步数和耗时。

TrGP_ω 还包含受约束的非线性核组合；只实现上述线性组合 TrGP_αβ 不能代表完整 TrGP_ω。原文的两层线性层、一层乘积层、两种 RBF 与一种线性基础核是 UJI 复现应进一步核对的配置。不要擅自用任意 MLP 的嵌入 RBF 替代后仍沿用论文方法名。

## MetaLoc 方法卡

原文：[MetaLoc, JSAC 2023](https://arxiv.org/abs/2211.04258)，DOI 10.1109/JSAC.2023.3322766。作者代码 [StatFusion/MetaLoc](https://github.com/StatFusion/MetaLoc)。本轮已克隆并阅读实际 `master` 分支，而不是停留在只有入口说明的 `main`。完整代码证据见 `METALOC_AUTHOR_CODE_AUDIT.md`。

在可复用机制上，需要比较的是：相同网络、相同历史数据和相同目标更新预算下，元初始化是否比普通预训练更利于少样本适应。最基本的外层目标为

\[
\theta'=\theta-\alpha\nabla_\theta L_S(\theta),\qquad
\min_\theta\sum_\tau L_{Q_\tau}(\theta'_\tau).
\]

对一步更新，完整梯度包含 (I−α∇²L_S)ᵀ∇L_Q；作者已公开代码中的 `autograd.grad` 没有 `create_graph=True`，不能称其自动保留了完整二阶 MAML。这是代码机制辨认，不是对一阶近似有效性的否定。其 `meta2.py` 又有额外的域间训练流程，不能用上述最简公式概括全部实现。

两个公平性要求来自我们的任务，而不是声称论文原协议错误：

1. 当前任务是目标新位置的坐标回归。作者 loader 的源任务在相同参考点类别内拆 Support 和 Query，CNN 输出固定90类，随后把类别编号映射到固定坐标。改变为520维 RSSI、二维回归和位置不重叠 Query 是实质性适配。改后应标注“MetaLoc 机制的 UJI 回归适配”，不能声称直接复现其 CSI 成绩。
2. 作者实现对辅助 `x_qry` 使用 `bn_training=True`，最终 `x_test` 则用 False。必须核对 loader 中两者来源，不凭名称把辅助集当最终评测集。若 UJI 适配把最终 Q 送入前者，预测就会依赖该批评测特征；应单列此权限或改造状态流程。没有使用 Query 标签更新并不自动等于归纳式预测，但也不能据此声称作者最终测试集已泄漏。

普通预训练对照应直接训练同一个最终坐标预测器，再按相同 Support 更新相同步数。不要重用 learned-map v1 的临时辅助头对照；该对照存在特征尺度自由度，不能隔离元学习带来的收益。

## AGML 方法卡

本轮新增核实：[Attentional Graph Meta-Learning for Indoor Localization Using Extremely Sparse Fingerprints](https://arxiv.org/html/2504.04829v1)。出版登记为 **TMC 25(6), 8718–8734, 2026**，DOI [10.1109/TMC.2025.3649637](https://doi.org/10.1109/TMC.2025.3649637)。发表元数据与作者稿内容分别核对；本轮读到的是2025年4月作者稿，未取得正式版全文，不能保证两个版本所有细节相同。

作者稿的机制链为：CSI/CIR 嵌入距离 → 学习邻接关系 → 图注意力聚合 → 任务级元学习。数据来自实测与环境数字孪生；已读版本没有 UJI 结果。作者 GitHub 账号已查到的 `GNN-For-localization` 对应 ICASSP 2021 前序论文，**不能当作 AGML 官方实现**。本轮没有确认 AGML 可用作者代码。

从 §IV-B 与公式14至17抽出的重要协议事实是：源任务的 Support 与 Query 共用所有节点特征，仅标签子集不同；目标场景也在一张包含有标签与无标签指纹的图上适应。因而图的节点集合本身是一项数据权限。

以下是我们把该机制映射到部署流程后的推导，不是论文定理：设 S 为标注 Support，U 为更新阶段无标签扫描，Q 为评测扫描，A_θ 为构图函数。如果适应使用

\[
G_\theta=A_\theta(X_S,X_U,X_Q),\qquad
\theta'=\theta-\alpha\nabla_\theta L_S(G_\theta),
\]

即使损失只读 y_S，θ′ 也可能通过图边、消息传播和归一化依赖 X_Q。于是“不读 y_Q”不足以证明 Q 没有参与适应。这种传导式设置本身成立，但它不是我们此前的“用独立 U 适应，随后预测新 Q”。

若研究独立 U 更新，应先使用 A_θ(X_S,X_U) 完成适应，再规定单个新查询如何接入已有节点、边是否重算、参考节点是否反向更新。三种选择会给出不同预测函数，不能等结果出来再命名。本轮不预先发明其中一种结构；先把作者机制与我们实际需要的在线接口分清。

这条研究链值得优先跟进的部分是**学习什么关系可以迁移，以及关系怎样在少样本条件下改变**。目前只有方向依据，没有证据证明去掉 CIR、数字孪生和全图权限后仍保有原论文增益。

## 已有 DKT 结果的作用

不能重复把 DKT 当作未尝试的路线。只读核对了兄弟工作树 `DKT-UJI/docs/DKT_SELECTED_RESULTS.md` 与 `DKT_DIAGNOSTICS.md`：10000次源更新、3个训练种子、每目标20组10位置×3扫描 Support，B0F3/B1F3/B2F4 为9.608±0.575、23.487±1.333、18.961±2.811 m。测试时没有参数梯度更新。

这证明本项目已有学习型核与条件适应实验；不能再声称所有已有方案都“没有学习”。它也没有证明学习型路线无效：这些实验没有使用与 TPM 相同的7对楼层、历史地图权限和后期 validation，不能跨协议比较数值。当前不重跑 DKT、不改该工作树，也不依据三个楼层结果推导“UJI 的可学习自由度已经饱和”。

## 统一比较前的执行约束

以下是待冻结的比较契约，缺少具体索引与源端选参范围，尚不允许据此启动正式训练。

| 状态 | 能看到的数据 | 需要固定的行为 |
|---|---|---|
| 历史学习与选参 | 外层源建筑内历史标签及源端模拟任务 | 外层目标建筑不参与元训练或选择；按位置划分源任务 Support 和 Query |
| 目标场景提供历史资料 | 每个目标对应的旧楼层地图或原始历史扫描 | 若 TPM 使用该资料，外部方法也要获准使用；明确它属于部署上下文而非宣称目标建筑从未出现 |
| 目标少样本适应 | 同一份 K 位置、每位置相同扫描数及标签；部署更新实验另给独立 U | 每方法记录目标优化次数和耗时；不要求所有方法零次更新来人为限制文献基线 |
| 新位置定位 | 当前查询的 RSSI；已冻结的适应状态 | Query 标签只进评估；不临时根据整批 Query 更新 BN、核参数或图 |
| 单独的全图协议 | 预先声明的整批 Query 特征 | 允许作者传导式机制，但单列结果，不与独立 U 更新混报 |

标注量应同时写 K 个位置和总扫描数；30条扫描并不总是10个位置×3条。K=3/5/10 的位置集合应预先固定并尽量嵌套。原论文复现使用其原协议，统一协议另建适配结果；不得用改变了数据权限的失败适配代表原论文。

至少需要同最终预测器的普通预训练加适应、元训练加适应、直接迁移核和 TPM 基线。UE-GLoc 的近期 UJI RSSI 成绩作为另一路外部性能参照，待作者实现或充分实现细节可核验后进入运行矩阵，不能凭标题拼一个图模型代替。预算不足时缩减研究问题，不删掉必要的强对照而保留自研模块。

## 实现前仍须解决的问题

- TrGP 原数值复现缺输出缩放、二维输出处理、采样协议及作者实现；按论文重写可先做机制核验，但须单独标注差异。
- MetaLoc 作者代码存在独立第二域样本与标签配错等问题。保留原版快照，后续修复补丁逐项对应原文；不把仓库原样运行失败当算法失败。
- AGML 正式版全文、作者实现及 RSSI 适配条件尚未闭合。不能因为是 TMC 2026 就忽略其额外输入。
- 目前 UJI 和已有楼层结果都已多次观察。新方向需要补充可冻结的外部数据检验；不能把重新切分称为全新盲测。

这些缺口限制当前可做的性能结论，不是停止研究的理由。下一项具体工作应是补齐最高优先级外部基线的复现规格；在此之前，TPM、漂移项和新的图结构都不获得默认的主方法地位。
