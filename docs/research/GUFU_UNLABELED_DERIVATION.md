# TPM 接续：GUFU 启发的无标签地图重构（实验前推导）

日期：2026-09-30。基点 ab1a60b；分支 tpm-gufu-unlabeled。此文件在实验实现和结果之前写定。

## 1. 接手事实与必须纠正的解释

已检查用户指定 JSONL 的用户请求、阶段总结、关键工具调用及原分支代码/文档。主线为跨楼层先验 → 锚点 GP → Tobit 匹配。TPM 历史 validation 10.31 m 是待核验的参考。v2/3、潜在 EP、长程协方差等已有负结果，不重新叠加。

`100` 的数据事实只是“未报告”，删失加随机漏检是建模假设；不能声称所有未报告都由物理阈值造成。−110 是观测向量的编码，不是潜在场测量。TPM 的地图是该编码的条件均值；Tobit 匹配是有效的打分规则，不能把编码均值与真实潜在 dBm 混成严格统一生成模型。

旧的留一先验排除了目标楼层，但全局四参数及曾看过的历史 validation 使其并非新的完全盲测。旧 LOPO 仅对选参表去掉一行，其他训练任务可能以该层为下层，且其先验可能见过被留出层；不是严格外层嵌套留一。此次不以该指标证明跨楼层泛化，只开展配对开发实验，明确验证边界。

## 2. 文献与代码证据

- Chiu et al., GUFU, IMWUT 9(1), 2025, DOI 10.1145/3712277；原文来自 Zotero TY7BNY8Z，并核对作者 PDF https://cse.hkust.edu.hk/~gchan/papers/IMWUT25_GUFU.pdf 。重点是 §5.2 式(5)–(9)：无标签指纹到坐标，再由坐标重构固定位置的指纹，并用虚拟邻接边约束一致性。本文是同场地时间更新，不是跨楼层少样本；GNN/新增 AP 预测不是此次必要前提。
- 官方代码 https://github.com/khchiuac/GUFU ，检查提交 e1f14c73165daceead6992b5047507704fb0d7c5。`util.py:k_virtual` 用余弦近邻构虚拟边；`sage_ve.py` 为图聚合，`pred.py` 为更新入口。它与论文的阈值邻接并不完全相同。`sage_ve.py` 导入未提供的 `utils`、`config`，类定义 `LossFunc(torch.nn.Module, sigma)` 的 sigma 未定义，`pred.py` 调用 `run` 缺少 model 实参；故不能把当前代码称为直接可复现实现。没有自行拼一个 GNN 冒称官方复现。本轮直接复用原仓库的先验、GP 校正及 Tobit 权重，矩阵分解用 SciPy 成熟实现；新增加的闭式求解逐项对应下述推导。未复制 GUFU 网络代码。
- Sorour et al., *Joint Indoor Localization and Radio Map Construction with Limited Deployment Load*, https://arxiv.org/abs/1310.3407 ：以少量校准点固定无标签信号流形与物理地图的对齐。借鉴的是对齐可辨识性问题，不假设 UJI 存在真实连续轨迹。
- Huang et al., *An Online Radio Map Update Scheme for WiFi Fingerprint-Based Localization*, IEEE IoT J., 2019, https://ieeexplore.ieee.org/document/8695724/ ：扩展 GPR 考虑噪声位置标签，支持保留位置不确定性而非把预测坐标当真值。
- Cozman, Cohen & Cirelo, *Semi-Supervised Learning of Mixture Models*, ICML 2003, https://aiinternational.org/Library/ICML/2003/icml03-016.php ：模型失配时无标签样本可使分类更差。因此重构下降不等于定位改善。

检索矩阵：{fingerprint/radio map}×{unlabeled update/crowdsourcing}；{cross floor}×{semi supervised/manifold alignment}；{Gaussian process radio map}×{noisy location/update}。Semantic Scholar 限流 429，OpenAlex 三组交叉查询补到 2012 manifold alignment、2019 time-series Laplacian 等；网页检索及 GUFU 的参考文献补到以上原始来源。本次为围绕具体机制的有界调研，不宣称穷尽或滚雪球收敛。轨迹/HMM 方法需要 UJI 不保证的时间连续性，暂不纳入。

## 3. 推导：只扩展地图校正一步

设固定地图位置 P=(p_j)，锚点坐标 S，TPM 的锚点后地图 F0∈R^{M×A}。新增扫描仅有 X∈R^{N×A}（100 仍编码 −110），不读取其真实坐标。最终仍用原 Tobit 打分匹配。

### 3.1 冻结软对应，避免循环自证

先以 F0 和既有匹配参数构造 H_ij=softmax_j score(X_i,F0_j)。H≥0、每行和为1，是新扫描节点连向地图节点的加权二部图。它是温度化打分形成的软对应，不宣称为校准过的真实后验。只计算一次，不用更新后的地图反复重估 H。

预测坐标 H P 通常位于真实候选之间；若先取其均值坐标再做 GP，会把多峰不确定性压成一个虚假位置。保留 H，直接以 H F 重构扫描。此为 GUFU 式(8)邻接一致性的线性、行归一化特例，非完整 GUFU。

### 3.2 更新的先验来自已有锚点 GP

沿用 ℓ=40、λ=0.3，RBF 核 k。锚点条件协方差

C=K_PP−K_PS(K_SS+λI)^{-1}K_SP.

在原地图节点做剩余更新 Δ；锚点自身的检索原型保持不变。C 使锚点附近的后续更新更保守。F0 的均值沿用旧 TPM（包含 lookup 和裁剪），所以 C 在这里是有明确来源的平滑正则，不把整个流水线称为精确 GP 后验。

### 3.3 一个目标、一个新自由度

令 η≥0 表示整个无标签批次相当于多少倍的 K 个锚点；τ=ηK/(λN)。解

J(Δ)=1/2 tr(Δᵀ C^† Δ)+τ/2 ||H(F0+Δ)−X||_F², Δ∈range(C).

若 C=LLᵀ、Δ=LB，则

B*=(I+τLᵀHᵀHL)^{-1} τLᵀHᵀ(X−HF0).

对称正定系数矩阵，所有 AP 共享一个分解；没有新网络、梯度训练或额外损失堆叠。η=0、N=0 精确退回 TPM。特征不变而批次重复时，1/N 归一化保证结果不变，避免将重复扫描错误地当成更多独立证据。因子 L 丢弃小于 max_eigenvalue×1e−10 的数值零特征值，记录秩。

沿用地图值域裁剪 [−110,0]。上述闭式最优性仅对裁剪前成立，裁剪后不是该二次目标的精确解；分别记录裁剪率及前后重构误差。

### 3.4 为什么不直接加权伪标签

另一个常见目标是 Σ_ij H_ij||F_j−X_i||²。它等于 ||HF−X||² + Σ_i Var_{j~H_i}(F_j)。额外的方差项会惩罚候选间差异，使本来用于定位的地图纹理变平。上式保留重构约束，不强迫一个多峰扫描同时在每个候选处成为真值。代价是 H 秩不足时更新不可辨识，只能依赖 C 和有限 η；无标签数据绝不会凭空提供绝对坐标。

### 3.5 成立条件、可证伪预期

1. H 至少在局部有正确对应；错误关联会传播错误。若真实坐标关联显著改善、实际 H 不改善，瓶颈是对齐，而非还缺一层网络。
2. 无标签采样覆盖目标区域；改变采样密度会改变目标，不假设均匀占据或强制双随机传输。
3. 以扫描重构换取地图改善只是代理目标，必须在独立 Query 上评价定位。
4. 同一批 X 也用于构 H，会有选择偏差；不把重构降幅当机制成功。固定 H + 独立 Query + 置乱 H 对照用于揭示此问题。
5. 新 AP 在旧图和锚点都无几何证据时，H 只能由其余 AP 提供定位，可能无法辨识；不宣称解决 AP 增删。

## 4. 实验前冻结的计划

- 先实现结构测试：η=0/N=0 回退；解的一阶残差；重复批次不变；置换不变；不接收 U 坐标；原 Tobit 预测数值等价。
- 历史 7 对，先验只由不含当前目标层的楼层拟合，原四参数固定 (40,0.3,12,−85)。不改原模型。
- 每层 20 个配对 episode，K=10×3；非锚点位置一半 U、一半 Q，两者坐标组隔离。最多600个 U 扫描、300个 Q 扫描，均固定随机流。U 坐标仅由评估器用于拆分与诊断，不进入实际模型。保存行 ID 和数据哈希。
- trainingData 上比较 η∈{0,0.1,1,10}，以楼层等权 MDE 选 η（包含关闭更新）。随后冻结选择 JSON，再打开官方 validation；validation RSSI 不参与构图/更新。历史 validation 已被前人查看，本次只是冻结后的开发验证。
- 验证使用20组原 TPM 支持集（seed=1001），独立随机流拆 U/Q，避免拆分消耗随机数改变支持集；完整保留每次结果。
- 机制对照固定 η=1：H 行置乱（保留 X 与边权边际，破坏对应）；oracle H（用 U 真坐标取最近原地图点），后者明确属于额外标签诊断，绝不列为可部署方法。同时记录 U 预测位置误差、H 空间离散度、地图更新幅度、重构降幅。
- 只有实际无标签方法在独立 Q 和冻结后 validation 上有一致证据才建议推进。若无收益保留负结果，原 TPM 仍为默认。
