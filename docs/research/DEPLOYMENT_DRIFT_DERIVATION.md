# 部署期无标签更新：审查、推导与实施边界

日期：2026-09-30。接续 GUFU v1（42f5484）及 learned-map v1（34cd89d）。
状态：**理论审查阶段；尚未实现新定位方法，尚未运行新性能实验**。本文件先于本轮反例检查与数据元数据审计写入。旧实验的预注册、代码和结果保留，不倒写历史。

## 1. 综合判断

暂不扩展 learned-map 的网络和超参。保留它的建筑外层隔离协议；研究重心转到“旧时期建立的跨楼层地图，如何利用部署期无标签扫描更新”。这是任务信息发生变化，不是换一个更大的函数拟合器。

TPM 的 rho、beta、观测参数已经由历史数据学习。准确说法是“缺少经多任务训练的神经适应机制”，不能说“没有学习”。学习核 v1 只改善约 3.18 cm，且预训练对照的表征尺度不识别，因此不足以支撑继续加网络。历史 LOAO、Matérn、长程协方差负结果也降低了再改空间核的优先级，但它们没有证明所有表示学习都无效，更不可能事前推出恰好 3 cm。7 个相互重叠楼层对也不是 7 个独立任务；扩展 episode 数不能创造建筑/时间域多样性。

本轮收到的审查含部分截断文字。这里只审查其中可以明确辨认的命题，不补写截断内容。

## 2. H 是线性算子，还是位置概率？这是两种模型

先对单 AP 写式子。若 **已知外生** 测量矩阵 H，规定

    f ~ N(m,C),  x = H f + epsilon,  epsilon ~ N(0,R),

则精确条件均值为

    E[f|x,H] = m + C H^T (H C H^T + R)^(-1) (x-Hm).

v1 的闭式重构在裁剪前具有这种正则化形式，但 C 是无量纲核、噪声由 eta 等效设定；m 还经过 lookup/clip。不能因此把整个 TPM 叫作同一生成模型的精确后验。

真实 WiFi 扫描通常来自一个未知位置 J_i，而不是多个位置的线性平均。若外生位置概率为 pi_ij，且先暂用高斯观测：

    p(x_i|f) = sum_j pi_ij N(x_i; f_j, sigma^2).

这不等于 N(x_i; sum_j pi_ij f_j, sigma^2)。即使只做矩匹配，也至少有

    Var(x_i|f) = sigma^2 + sum_j pi_ij(f_j - sum_k pi_ik f_k)^2.

若 f 自身有后验均值 m、协方差 C，随机位置扫描的方差还包含 sum_j pi_ij C_jj；线性平均 Hf 的方差却是 H_i C H_i^T。后者会把位置的不确定性平均掉。多个 AP 共用同一位置，还会产生 AP 间的混合相关性。

v1 的 H 又由本条 x 在旧图上的打分计算，因此并非外生位置先验。固定 H 可作为一个代理更新步骤，不能把用同一个 x 形成的 H 再当成独立证据。若采用 EM，责任度可以由 x 计算，但 M 步需对应完整似然的期望；其高斯观测项是 sum_ij H_ij(x_i-f_j)^2，不是 (x_i-H_i f)^2。前者的候选方差项有明确的 EM 来源，不能普遍判定它“错误”，也不能把后者称作等价替代。v1 是一种有意选择的重构代理目标。

两节点 f=(-80,-40)、pi=(1/2,1/2)、sigma=2：真实扫描集中在 -80 或 -40 附近，平均模型却集中在 -60。两者即便均值相同，方差和似然也完全不同。这是实现前必须保留的反例。

## 3. 常数偏移较容易估计，但并不免疫错误对应

先在“完整、未删失、加性”理想模型里讨论。若真实位置关联为 H*，

    x = H* f0 + b 1 + epsilon,
    b_hat = mean(x - H f0),

则

    E[b_hat] - b = (1/N) 1^T (H* - H) f0.

H1=1 只保证 H(b1)=b1，不能保证 Hf0=H*f0。前者是常数场的代数性质，后者才决定偏移估计是否有偏。

反例：旧图两个位置分别 -80、-60，真实在第一点且 b=+5，所以 x=-75；错配第二点后得到 b_hat=-15。还有一个更强的不可识别例子：观测全是 -60，既可能是第一点占据且 b=+20，也可能是第二点占据且 b=0。未知占据分布与漂移可以完全混淆。

有条件成立的结论：若只把 H 的行置乱、仍使用全部 N 条扫描的等权均值，则 1^T H 不变，常数估计不变。**行置乱不敏感 != 任意错误对应不敏感**。若更换了列占据边际，或使用 AP 特定检出筛选/异方差权重，此性质也不自动成立。因此 v1 行置乱导致整场定位变差，不能单独用来证明常数分量是否正确。

## 4. 潜在信号变化和插补均值变化不线性

### 4.1 严格沿用当前 cross_floor.py 的模型

当前代码并非单一硬阈值 Tobit 生成模型，而是带检出链接的两部分模型：

    L ~ N(mu,v)
    D|L ~ Bernoulli(h Phi((L-theta)/s))
    R|L,D=1 ~ N(L,sigma_t^2)
    X = R if D=1 else c,  c=-110（仅编码）.

检出噪声与数值噪声在给定 L 后按该模型分开。令 q=sqrt(s^2+v)、z=(mu-theta)/q，则由高斯积分

    T(mu,v) = E[X]
            = c + h[(mu-c)Phi(z) + (v/q)phi(z)].

这与 models/cross_floor.py:prior_map 一致（但代码另有全未见 AP 强制 c、最后 clip）。若潜在场整体增加 b，则编码地图应变化

    Delta_X(p) = T(mu(p)+b,v(p)) - T(mu(p),v(p)),

而不是 Delta_X(p)=b。其局部导数为

    dT/dmu = h[Phi(z) + ((mu-c)/q)phi(z) - (v z/q^2)phi(z)].

即使 v=0，导数仍是 h[Phi(z)+((mu-c)/s)phi(z)]，依赖位置，阈值附近还可能超过 1。合成例取 h=1、s=5、theta=-85、b=5，在 mu=-95、-85、-65 三处的编码变化不同；这是模型的必然性质，不是用 UJI 分数解释出来的。

标准硬阈值模型 Y~N(mu,sigma^2)、D=1[Y>theta] 的编码均值另为

    T_hard(mu)=c+(mu-c)Phi((mu-theta)/sigma)+sigma phi((mu-theta)/sigma).

不要把它与上述两部分模型混用。当前最终 tobit_weights 又把编码原型当高斯中心并对未检出用 logPhi 打分，这是一条既有的有效打分规则，尚不是跨楼层先验、锚点更新与匹配共享的严格似然。

### 4.2 为什么不能简单把现有 F0 反解回潜在场

现有 F0 已叠加编码空间 GP 残差、裁剪和实测锚点原型，单个编码均值不能唯一恢复 (mu,v,h,theta,s)。旧层全未见 AP 还被硬置为 c，进一步丢信息。因此禁止直接写 latent = F0，或对 F0 全图加一个“物理 dB 偏移”。

两条自洽路径需明确区分：

1. 保留编码地图，只估计**编码空间有效修正**；可作为工程基线，但不能解释为 AP 发射功率变化、手机增益变化的物理估计。
2. 保留/重建潜在场分布，直接用 D 与实际检出值 R 推断漂移，再经 T 映射到编码原型。这样观测非高斯，未知位置还需混合；一般没有原来的线性闭式解。需单独证明近似推断、旧场初始化和匹配是否一致，再决定是否值得实现。

不因第二条写得更“物理”就默认采用。已有潜在 EP 路线的负结果必须保留；本轮不能借重新命名再重复整套复杂模型。

## 5. 两个时期的场：旧锚点约束什么

令旧时期场为 f_old(p)，旧 Support 为 S_old。后期场写成

    f_new(p) = f_old(p) + d(p),
    d(p)=b+u(p),  b~N(0,tau_b^2), u~GP(0,tau_u^2 k_ell).

若漂移在先验中独立于旧场，旧锚点约束的是 f_old，不是“d(S_old)=0”。在高斯线性近似下，给定旧锚点后

    Cov(f_new | S_old) = C_old|S + K_d.

不能只用 C_old|S 更新，否则会把旧锚点误当成后期仍然准确的钉子；也不能彻底丢弃 C_old|S，因为旧场估计误差依然存在。若为最小基线而把旧图当固定均值，只使用 K_d，应明确这是 plug-in 近似，且可能低估不确定性。

所有旧原型（包括锚点原型）都应按新时期更新或统一替换，不能一部分新、一部分旧。若使用数据驱动潜在模型，旧 Support 进入旧场似然，而非新场零漂移观测。

常数与长程场也会互相混淆：ell 趋于无穷时 K_d=(tau_b^2+tau_u^2)11^T，两个幅度不能分别辨认。需预先限制结构，或在固定参考节点上将空间分量加权中心化。不能用 U 的未知占据分布来定义“全楼层平均为零”。优先研究常数-only，只有源端证据要求空间结构时再增加它。

## 6. eta 和 1/N：不能只删除，必须替换它们承担的假设

v1 的 tau=eta K/(lambda N) 对应线性代理模型的等效 R=lambda N/(eta K) I（单位核幅度约定下）。总量归一化刻意使整批复制不变，这避免把完全重复数据当新增证据，但也会让真正独立扫描增加时不再按 N 积累同等信息。eta=10 在网格边缘仅说明该搜索没有括住更优候选，不能证明噪声必为零或继续增大会好。

若更换成概率观测模型，需要有 dB^2 单位的场幅度及观测方差；当前无量纲 lambda=0.3 不是每条扫描的物理噪声。R 至少要考虑测量噪声、位置混合、重复/同设备相关性和模型失配，不能只设成 sigma_t^2 I 后把“自然”当成已证明。

对于 N 次等方差、两两相关系数 rho 的重复扫描：

    Var(mean epsilon)=sigma^2 [rho+(1-rho)/N].

rho=0 才是 sigma^2/N；rho→1 几乎不增加信息。真正独立的新扫描应增加信息，拷贝同一行则不应。若不知相关结构，先把精确重复合为一份、报告扫描与位置覆盖预算，再做源端噪声敏感性检查。不能按隐藏的 U 真位置聚合给模型，否则偷偷使用标签。

## 7. 数据权限与评价计划（尚未冻结方法超参）

问题定义：t0 旧楼层地图 + t0 目标层 K 个已标注锚点，t1 获取同目标层无标签批次 U，更新后定位未参与更新的 Q。所有方法使用同一份 K、U、Q、已知楼层权限。承认批量 U 是额外部署资源，不能与不使用 U 的旧分数直接比“算法优劣”。

1. 外层按建筑留出；跨楼层统计量和原 TPM 参数只由其余建筑选取。保留 learned-map 的防泄漏实践，移植时需独立代码审查，当前 GUFU 旧脚本不会自动具有该隔离。
2. 若使用其余建筑 validation 构造真实漂移任务选参，这些行正式改名为 source-later，属于训练/开发权限；测试建筑 t1-Q 仍不可访问。**这是相对旧协议的明确变化**。若只用 trainingData 选参，则必须承认没有直接的跨时期漂移训练信号，不能把跨楼层差异当作相同漂移分布。
3. 历史 validation 已被反复看过，即使重新按建筑划分也只能叫开发基准，不能恢复“盲测”。
4. 第一协议是 t1 validation 按位置组拆成 U/Q，位置标签只用于评估器分区，不传模型。名为“同一后期采样集合上的批量适应”，不自动叫在线预测。若扫描重复跨位置标注异常，还需按重复组净化。
5. 真正时间前瞻另设协议：按时间切 U 在前、Q 在后，同位置跨界时净化，并报告剩余覆盖及设备变化；不能看分数后在两种协议间挑一种。
6. 设备组成必须审计。若一个共享 b_a 同时服务多手机，实际可能是 b_{a,d}，混合比例变化会导致错误。不能默认设备 ID 可用；主要 RSSI-only 方案不得读取 PhoneID/UserID，设备感知方案需单列权限。
7. 主对照至少包括：同一 Q 上的冻结旧 TPM；原 v1 更新但换成同一部署 U（明确它仍会冻结旧锚点）；候选常数-only；若有源端依据再做常数+空间。每种方法需要同等选参规则，拆分改变与结构改变不能混成一个增益。
8. U/Q 相同时间池共享随机效应；20 次拆分不是 20 个独立楼层。报告逐建筑/楼层差异和资源预算；旧 9.6078 m 对应完整 validation，不作为新 Q 子集的基线。

## 8. 本轮最小检查及执行前反向审查

### A. 纯数学反例检查

只用标准库和手写小例子，不读 UJI、不读模型权重、不训练、不算定位误差。将验证：位置混合与均值测量的方差差异；错误关联造成常数偏移偏差；H 行置乱的有限不变性；T 的非线性及解析导数；旧锚点后新增漂移仍有方差；相关重复的均值方差；Support 公共特征平移被距离消掉。

反向审查：输出只是这些代数命题的数值例，不可推出定位收益、真实漂移以哪一项为主、真实噪声有多大。检查断言应来自本文件公式，不从 UJI 输出反推。脚本不需要构造通用模型框架。

### B. 数据权限元数据审计

只读取官方两个 CSV 的位置组、建筑/楼层、设备/用户 ID 和时间戳，用于判断部署假设是否可实行。文件哈希可读取全部字节，但不计算 RSSI 分布或定位分数。输出每层行数、位置数、每位置扫描范围、时间范围、设备组成及训练/后期的坐标/设备重叠。已有训练加载器丢弃设备/时间，这一步须直接读 CSV，不能从 load_floors 的输出臆造时间任务。

先确认远端主机 Linux/ray-web，使用已读 gpu-cluster-ops 规则，仅在 CPU 上执行只读标准库统计；不调用训练入口。结果属于协议审计，允许在冻结方法前进行，需公开记录已看到这些元数据。原始坐标和匿名个体行不进入报告。

## 9. 实施门槛与当前决定

优先推进部署信息更新，学习核分支归档为负/弱结果。**本轮不把“潜在常数+空间场”直接实现为插补地图上的线性加法，也不立即删掉 eta 开跑。**

正式新方法实现前需明确：编码修正基线还是潜在模型；占据与漂移混淆采取何种可审计假设；设备混合如何处理；漂移噪声/幅度由哪些源任务得到。只要这些问题尚未闭合，继续的是可辨识性和观测层推导，而不是扩大模型或实验网格。
