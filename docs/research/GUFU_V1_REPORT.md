# GUFU 启发的 TPM 无标签地图更新：首轮结果

## 结论

在原 TPM 的同一组 20 次锚点采样上，新方法将 7 个历史楼层的官方 validation 等权 MDE 从 **10.3068 m 降为 9.6078 m（改善 0.6990 m，6.78%，6/7 层改善）**。冻结后同日、与无标签池位置隔离的 Query 从 **8.0856 m 降为 7.6847 m（改善 0.4009 m，5/7 层改善）**。

这支持继续研究“无标签扫描重构固定地图”这条主线，但不代表 GUFU 的完整复现、不构成新楼层盲测证明，也不声称统计显著。B0F1 明确退化，B0F2 与 B2F2 的 validation 平均改善很小。

## 具体改动与数学依据

保留 ab1a60b 的跨楼层先验、锚点校正和最终匹配。新增一步放在锚点校正之后：

1. 用原 Tobit 打分建立扫描到固定地图节点的软对应 H。
2. 在锚点条件协方差 C 约束下，更新地图 F0，使 H(F0+Δ) 能重构新扫描 X。
3. 锚点自身原型保持不动，仍用原匹配规则输出坐标。

目标是 `½ tr(ΔᵀC†Δ) + ηK/(2λN) ||H(F0+Δ)−X||²`，有闭式正定解。唯一新增的选择量是 η。详见 [实验前推导](GUFU_UNLABELED_DERIVATION.md)；该文档先于实现提交（f2578bf），实验实现提交为 70b60b0。

这借鉴 GUFU §5.2 的图关联与指纹重构思想。官方仓库静态问题、复用代码位置及准确提交见 [代码来源](CODE_PROVENANCE.md)。没有增加 GNN、另一套编码器或多项额外损失。

## 数据权限与冻结顺序

- 每层20个 episode，每次10个锚点位置×3扫描。
- 其余位置随机分成互不相交的 U 与 Q；最多600条 U、300条 Q。评估器可用坐标做分组，实际更新接口只收到 U 的 RSSI。
- U 来自 trainingData，官方 validation 的 RSSI 和坐标都不参与更新。
- 原参数固定 ℓ=40、λ=0.3、σ=12、θ=−85；跨楼层先验排除当前目标楼层及包含它的转移对。
- 先在 trainingData 选择 η，再写入 selection.json，最后才加载官方 validation。源端选择 η=10，**没有根据 validation 改选 η=1 或另扩网格**。
- η=10 是此次离散候选的边界，不声称已找到连续最优值。
- 继承的四参数来自历史全局开发，历史 validation 也曾反复查看；旧 LOPO 不等于严格嵌套留一。因此本轮称开发验证，不包装为干净的跨建筑外推。

原 TPM 与旧 outputs/tpm_v1/results.json 的逐层差异最大只有 **4.29×10⁻¹² m**，排除了支持集改变或基线不一致造成假提升。

validation 中 B1F1 的20次采样有18次改善，B1F2为20/20，B2F1和B2F3为17/20；B0F1只有4/20，不能归结为单次采样偶然。B2F2只有10/20，均值0.08 m不作为稳定收益。这里的20次支持集共享查询数据，不能把140个 episode 当成140个独立楼层计算显著性。

## 机制对照与不能推出的结论

在开发阶段、**同一个 η=1** 下：

| 条件 | 独立Query / m |
|---|---:|
| 原TPM（不更新） | 8.3011 |
| 实际软对应更新 | 7.8146 |
| 将 H 的行置乱，再对应原 X | 11.0773 |
| 用 U 真坐标构最近地图节点对应（额外标签诊断） | 7.2835 |

置乱保留样本和边权的边际分布，却破坏其对应后，效果明显变差：实际对应关系提供了有效信息。真实坐标诊断进一步改善，说明对齐仍有空间；它用了最多600条扫描的真坐标，绝不能算实际无标签方法或公平基线。

validation 也保存了 η=1 的两个诊断；**不可把它们与选出的 η=10 直接比较来归因**。真实坐标的最近节点本身有量化误差，也不是理论性能上界。

## 下一轮应该解决什么

优先解决**软对应的可信度与跨场景选择偏差**，不是继续扩网络或按B0F1调特例。先从当前输出判断 H 的空间离散度能否识别定位错误，再在完全排除外层建筑的数据上校准；必须重新设计包含原四参数在内的外层隔离，才能声称跨建筑泛化。仅凭熵小就提高伪标签权重没有数学保证，过度自信的错误关联恰好会通过这种门槛。

本轮保留为独立研究分支；原 TPM 主线没有被合并或替换。
