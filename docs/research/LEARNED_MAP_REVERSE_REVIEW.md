# 从实际代码反推训练、适应和测试

日期：2026-09-30。**此审查在 v1 实验已经结束后完成**，不能冒充开跑前检查，也不修改 `LEARNED_MAP_DERIVATION.md` 的原始预注册。本文件先从公式和代码分析问题，不用成绩解释其成立与否。

结论：v1可作为一个受限的学习核基线保留，但当前对照还不足以单独归因“学到了更强的少样本适应机制”。在下面的问题完成逻辑闭合前，不启动后续结构实验或扩大训练。

## 1. 真正执行的阶段和状态

| 阶段 | 可以看到的数据 | 改变的状态 | 产物与不能看到的内容 |
|---|---|---|---|
| 源先验拟合 | 外层建筑以外的历史楼层；当前源任务还排除自身上层 | 观测噪声/检出统计、rho/beta等 | 当前源任务的初始地图；不使用外层建筑统计 |
| 基线选参 | 源任务Support和位置隔离Query | 选择ell/lambda/sigma/theta | 三折各自选择；不使用外层成绩 |
| 元训练前向 | 源旧图、初始地图、带坐标Support、Query RSSI | 此时模型参数固定，按Support解线性系统 | Query预测；Query坐标没有进入地图更新 |
| 元训练反向 | 上一步预测及源Query坐标 | 更新共享g_theta及优化器状态 | 梯度经过匹配和解析求解；目标层不会继承源优化器状态 |
| 普通预训练 | 源Query真实位置用于查旧图描述符，源Query RSSI作为残差标签 | 更新g_theta与临时线性头 | 是源地图场监督，Query位置在源训练合法；部署只在已知地图节点/Support位置求特征 |
| 目标适应 | 目标建筑自身的旧层完整地图、K位置×3扫描Support | 固定theta；构建Support残差并求alpha | 新地图；没有SGD，不读取Query坐标 |
| 定位测试 | 待定位RSSI、更新后地图与已知节点坐标 | 不修改任何模型/地图状态 | softmax加权坐标；评价器随后才读真坐标算误差 |

这是一种学习核的快速条件适应，不能因没有目标SGD而否认其学习性质。但“整个表示随Support内容适应”是更强的性质，当前结构没有实现。

## 2. 核关系不读取Support的实测RSSI：适应能力比原叙述更窄

在 `models/learned_map.py:94–97`，网络输入是旧图/先验描述符。Support的描述符由其坐标在旧图上插值得到，不包含新的RSSI残差。固定旧图和Support位置后，核与传播矩阵

`A_theta = K_theta(P,S) (K_theta(S,S)+lambda I)^(-1)`

完全确定。Support实测信号只通过 `delta=A_theta r_S` 进入结果。

所以给两组坐标完全相同、但一组残差呈现全局偏移、另一组残差呈现孤立异常的Support，模型会使用同一传播矩阵。最后地图裁剪和定位打分可以非线性响应残差，但**传播关系本身不能根据残差内容重新选择**。这不是读不到Support，也不是实现错误；是结构表达能力的明确边界。

该性质可在训练前从依赖关系直接推出，不需要查看测试误差。它允许检验“跨任务训练固定的先验条件传播关系”，不能充分检验“依据新Support内容选择适应策略”。DKT支持前一种机制；CNP/ANP的上下文编码则显式处理输入-输出配对。依据：[DKT](https://arxiv.org/abs/1910.05199)、[CNP](https://proceedings.mlr.press/v80/garnelo18a.html)、[ANP](https://arxiv.org/abs/1901.05761)。三者的结论不能互相替代。

## 3. 普通预训练与部署距离存在尺度不可辨识：当前对照不能完整归因

普通预训练头为 `h(z)=w^T g_theta(z)+b`。对任意c>0，令 `g'=c g, w'=w/c`，监督预测完全不变，因而数据拟合项也不变；部署RBF却变为：

`exp(-c² ||g(z_p)-g(z_s)||²/2)`。

同样好的监督预测可以对应近乎恒定或近乎对角的核。权重衰减会偏好某些尺度，但这取决于参数化、优化器与正则，不能使监督目标直接识别后续定位所需的度量。

因此，即使相同初始化、相同网络、相同Query和训练步数，元训练与普通预训练之差仍混合了“任务目标”“表示内容”“度量尺度”的差别。现有比较只能说明这两个具体训练过程的效果不同，不能单独证明元学习机制优越。

另一个可事前预见的差异：普通监督MSE等权平均520个AP，其中大量未检出AP的残差接近零；定位损失通过检出与删失打分赋予不同AP不同敏感度。对照并未对齐有效信号的权重。

后续必须先决定要识别哪个问题；如要比较表示，需推导尺度规范或仅源端的核尺度校准，再预注册；若要比较端到端目标，就准确限定结论。不能根据本次外层成绩补选尺度。文献旁证是TADAM专门区分了度量缩放与任务条件化，不能把其分类提升当成本项目的效果证明：[TADAM](https://proceedings.neurips.cc/paper_files/paper/2018/hash/66808e327dc79d135ba18e051673d906-Abstract.html)。上面的不可辨识证明为本项目针对实际代码的代数推导。

## 4. 定位输出被候选坐标凸包限制：扩大网络也突破不了

`match`输出 `p_hat=sum_j w_j p_j`，softmax使w_j>=0且sum w_j=1。因此

`p_hat ∈ conv(P_old ∪ S)`，

`||p_hat-p_true|| >= dist(p_true, conv(P_old ∪ S))`。

任何只改候选RSSI/匹配权重、不改变候选位置的结构都受这个界约束。这不能证明当前误差主要来自覆盖不足，但应在选择结构前明确：如果部署位置超出旧图和少量锚点覆盖范围，本模型再强也无法预测到凸包以外。正式实验前应在源任务上查看几何覆盖；不能用目标查询坐标扩地图再当作可部署方法。

该结论只需当前解码公式，不依赖实验数值，也不需要借助论文权威。

## 5. 特殊输入可以提前说明模型究竟学不到什么

- **旧层从未见过某AP**：该AP的7维描述符在所有位置恒定（先验也为-110），所以g在各点相同，特征核恒为1；该AP严格退回固定空间GP，不能从元训练获得有区别的传播关系。这是表达边界，不是本次失败病因的证明。
- **Support残差全零**：delta=0，与theta无关；模型不能主动修正锚点没有显露出的先验偏差。
- **单锚点**：自核为1，因此 `delta_a(p)=k_theta,a(p,s) r_s,a/(1+lambda)`；只能传播该AP的一个标量残差，不能识别任意空间变化。
- **空Support**：严格返回先验地图，已实现。存在先验但没有锚点不是一个已训练的新任务条件表示。
- **常量特征**：核退回空间RBF；且RBF的特征距离平方在所有g相等处的一阶梯度为零。非零随机初始化和梯度测试避免了一个明显死点，但不证明真实训练任务里梯度足够有信息。
- **最后输出层的4维偏置**：在g(z_p)-g(z_s)中相消，不影响核。名义196参数中这4个只会受权重衰减影响，不应把参数数量等同有效自由度。

## 6. “核因子小于1”不等于“整个更新只会更保守”

虽然逐项 `K_theta(p,q)<=K_space(p,q)`，但条件更新还包含 `(K_SS+lambda I)^(-1)`。改变K_SS会改变系数大小与符号，不能从逐项核减小推出delta逐项减小或噪声影响必然变弱。

令alpha=(K_SS+lambda I)^(-1)r，则

`d delta = (d K_PS) alpha - K_PS (K_SS+lambda I)^(-1) (d K_SS) alpha`。

两项可以相互抵消或放大。正定性保证可解，lambda给出逆算子的谱范数上界1/lambda，但不保证定位变好或经验上更稳健。原推导关于因子[0,1]的陈述只指核元素，不应扩写成更新幅度保证。

## 7. 源训练与目标测试还有哪些状态不同

源任务先验是排除自身上层后的交叉拟合；部署先验用全部源任务拟合。两者的统计样本量和任务组成不同。这样做有防泄漏理由，但网络训练时见到的先验质量分布不自动等于部署分布，应作为任务构造条件解释。

元训练的Support和Query来自同一trainingData批次；官方validation还包含时间/设备变化。当前训练并未显式模拟这些变化，所以“跨楼层元训练”不能自动支持“跨时间、设备适应”的宣称。历史Cross-Device分支的已有结果需先核查，不能看到validation下降就新造设备解释。

地图值裁剪、真实锚点原型追加、连续核在锚点的预测与离散地图检索也是不同的状态。`field_support_rmse`量的是连续残差核在锚点的拟合，不是插值整张离散地图后的误差，也不是追加真锚点后的定位误差；后两者不能替前者掩盖拟合问题。

## 8. 审查决定

3. 下一结构的正式训练前，先明确要检验固定的可迁移核，还是由Support内容决定的关系；解决预训练对照的尺度解释，并说明几何覆盖与新AP边界如何影响研究问题。
