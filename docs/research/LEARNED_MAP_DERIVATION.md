# TPM 学习型地图适应：推导与首轮冻结协议

日期：2026-09-30。此文在新模型实现及训练之前提交。起点为 `42f5484`，分支 `tpm-learned-map`。

## 1. 可证伪的假设与已有证据

假设：在原地图给定的空间结构上，跨任务训练一个小型 AP 共享表示，以最终少样本定位损失学习锚点残差传播关系，能超过预设空间核、随机表示及普通监督预训练表示。

不是“神经网络必优于统计方法”。TPM 已估计 rho/beta，GP 条件化已是快速适应。改变的是训练目标与残差传播关系，而不是给已有方法换名称。

本项目 DKT / Support Ridge 已证明某些楼层存在表示学习收益，但跨层不稳定；MapMeta 是旧地图初始坐标加学习型坐标残差，开发平均收益仅约 0.26 m。GUFU 启发的固定软关联地图重构在旧协议上使 10.3068 m 降到 9.6078 m，但不是外层隔离结果。首轮改学信号地图残差，不将这些旧数字当新协议直接基线。

## 2. 文献思想与代码来源

- DKT, NeurIPS 2020：学习可迁移核，目标任务用条件预测，支持“学习型适应不必目标梯度更新”。论文 https://arxiv.org/abs/1910.05199；作者仓库 https://github.com/BayesWatch/deep-kernel-transfer ，已查阅提交 `61d95d6ab783be679c09803a33e3c2302287cbc4` 的 `methods/DKT_regression.py`。其原任务是图像/函数回归，原训练用 GP 边缘似然，不等同本轮定位 Query 元损失；未整包复制老 GPyTorch 依赖。
- MetaFun, ICML 2020：学习函数空间更新，而非仅学坐标回归参数。https://proceedings.mlr.press/v119/xu20i.html 。本轮借鉴更新函数/空间场的视角，不声称复现其迭代神经更新。
- TE-TNP, ICML 2024：空间条件函数的平移等变表示。https://arxiv.org/abs/2406.12409 ，代码 https://github.com/cambridge-mlg/tetnp 。本轮以相对距离核与无绝对坐标的描述符实现适用的对称性，不移植 Transformer。
- GUFU, IMWUT 2025：基于关系更新无线地图。https://arxiv.org/abs/2507.11038 。继承上一轮的地图更新问题定义；首轮不增加无标签软对应，避免混淆对应质量与有监督残差传播。

实际直接复用本仓库 `cells/fit_observation/fit_transfer/prior_map`、三邻居坐标插值、Support 聚合与 Tobit 打分公式；只新增可微的 AP 共享核条件化和按建筑隔离的实验驱动。每个直接复用文件记录哈希；Tobit 与 GP 的 PyTorch 版本必须对照原 NumPy/SciPy 实现验证。

## 3. 从 TPM 到学习型修正

目标层编码观测地图 `F(p,a)=F_prior(p,a)+delta(p,a)`。Support 在 K 个位置每处 3 扫描，按位置平均得到 `xbar_S`；残差 `r_S=xbar_S-F_prior(S)`。先验在锚点坐标的取值沿用三最近旧图节点、权重 `1/(distance+1)`。

UJI 的 100 代表未报告 AP；-110 只是缺失编码。这里拟合编码观测均值及匹配能量，不宣称整个流程是物理 RSSI 的严格生成概率模型。

每个位置/AP 的描述符 z 共 7 维：先验编码均值、旧图编码均值、旧图检出率、旧图已检出均值，以及该 AP 的全图最强已检出均值、全图有检出的位置比例、全图编码均值。强度统一用 `(value+110)/110`，无检出均值用 -110 编码。后 3 项在同 AP 的位置间恒定，提供不同 AP 的迁移背景；参数跨 AP 共享，无 AP ID 嵌入。Support 处 z 用相同三邻居插值。

网络 `g_theta:7 -> 16(tanh) -> 4`，196 个参数。学习核为：

`k_theta,a(p,q) = exp(-||p-q||²/(2 ell²)) * exp(-||g_theta(z_pa)-g_theta(z_qa)||²/2)`。

它是原空间 RBF 与学习特征 RBF 的乘积。二者均为半正定核，由 Schur 乘积定理，乘积仍半正定。lambda>0 时 `K_SS+lambda I` 正定，条件修正唯一：

`delta_a(P)=K_theta,a(P,S) (K_theta,a(S,S)+lambda I)^(-1) r_S,a`。

等价于 RKHS 中最小化 `||r_S-f(S)||² + lambda ||f||_H²`，由表示定理及一阶条件得到。关闭特征因子（恒为 1）精确退回原空间 GP；没有 Support 时修正为 0。网络不在目标任务做 SGD，少样本适应由上述条件化完成。

注意：此因子在 [0,1]，只能相对原空间核抑制关联，并不能任意放大长距离相关、产生负相关或表示所有跨 AP 耦合。限制降低容量，也限制可解决的问题。AP 间只共享网络参数，不做交叉残差混合。

不要把最后层置零：RBF 特征距离平方在所有特征相等处梯度为零，会使网络停在常数核。采用 PyTorch 默认非零随机初始化，随机控制保存完全相同的初始参数。

更新地图裁剪到 [-110,0]，追加真实 Support 原型，沿用 Tobit 匹配加权坐标。裁剪后不再宣称是上面无约束二次目标的精确极值。

## 4. 外层训练及普通预训练对照

元训练每次随机一个源迁移任务，K 从 {3,5,10} 等概率抽取，Support/Query 按位置隔离。优化 `mean sqrt(||Match(x_Q,F_hat)-y_Q||²+1e-6)/20`。这是接近 MDE 的平滑目标；Query 坐标只进入外层损失，不进入地图更新接口。梯度经过匹配、核及线性求解回传到 g_theta；ell/lambda/sigma/theta 在源端选择后固定。

普通监督预训练：相同 g_theta、相同初始化、相同任务与 Query 抽样序列和更新次数；接一个临时 4->1 线性头，从旧图描述符预测 `(encoded(x_Q)-F_prior(Q))/20`，优化均方误差。部署时丢弃临时头，用其 g_theta 做相同的核条件化。它不以适应后的定位效果训练，也不声称与元训练的损失尺度/计算成本相同；它是“普通信号残差预训练”这一具体控制，不能代表所有预训练方案。

每种方法 2 个初始化种子 {0,1}；Adam lr=1e-3，weight_decay=1e-4，梯度范数裁剪 5；1000 次更新、每次一个任务、Query 最多96扫描。预算固定，不按外层结果延长训练，不根据外层结果挑种子/检查点。每100步仅记录源训练诊断；最终固定第1000步。无全局 520 维 AP ID 记忆网络。

## 5. 数据权限与基线选择

历史7对同旧实验。3折分别留出 B0/B1/B2；每折源只包含另外2栋建筑的历史楼层。观测噪声、检出统计、rho/beta等全部重新拟合。拟合源训练任务先验时还排除该任务上层以及任何含该层的源转移对。部署先验用两栋源建筑全部历史转移拟合，再应用到外层建筑提供的旧楼层地图。

基线/模型共享的 `(ell,lambda,sigma,theta)` 用源端5个K10位置隔离episode/层、Query最多128扫描选择；候选 ell={20,40,80}, lambda={0.1,0.3,1}, (sigma,theta)={(12,-85),(16,-80)}，共18组。源层等权 MDE 最小者用于该折所有模型。该有限网格不是全局最优证明，也没有为学习核另选有利参数。

全部3折模型、基线参数与checkpoint哈希写入 frozen.json 后才读取官方 validation、构造外层目标 episode 和报告其成绩。基础CSV读取器会解析trainingData各层，但拟合接口只接收源字典；外层目标数据在冻结前不构造cell统计或参与计算。目标旧地图与K个Support为允许的部署输入。记录每个先验的实际源层和源转移对并断言外层建筑未出现。

历史上所有这些数据都已多次分析过，因此该协议保证本轮计算隔离，不恢复设计层面的全新盲测。只有3栋建筑，不能把楼层、Support抽样、AP、扫描当成独立建筑增加显著性。

## 6. 冻结评价与诊断

每外层楼层20个episode。先抽10个有≥3扫描的位置，每处3扫描；K=3/5/10依次取嵌套子集。Query固定为这10个位置以外的最多300扫描，各K、各方法、各种子完全共享。官方validation不参与更新，另计时间/设备偏移下的表现。K表示位置数而非扫描条数。

主方法：prior+support（无残差传播）、原空间TPM、随机特征、普通预训练、元训练。主比较 K10、楼层等权和建筑等权均报告；K曲线分别列出。2种子取均值并列差异，不挑最好种子。无U，因此不能与有额外无标签数据的旧9.6078 m直接排优劣。

K10附加冻结诊断：1) 打乱Support位置与扫描的对应，报告预测移动、MDE和Support拟合，而不是只凭MDE不变断言未读取Support；2) 将迁移先验替为旧层编码地图，重新计算对应描述符/残差，作为无重训的“去迁移先验”诊断，不能当作公平重训消融；3) 记录学习核因子、修正幅度与适应耗时。真实锚点在部署地图中会被追加，因此另报告仅校正场对锚点编码均值的RMSE，避免真实原型遮盖条件化失败。

## 7. 必须通过的验证与决策

- 常数特征时GP更新和最终定位对齐原NumPy/SciPy实现；避免大绝对坐标的float32相消，统一相对原点并用float64。
- 核PSD、lambda正定求解、有限差分验证可学习参数梯度（特别是穿过求解和最终匹配）。
- Support排列不变；地图节点/AP同步置换等变；平移坐标只平移输出；原型内Support/query位置隔离。
- 原方法/随机/预训练/元训练保存同一测试manifest，源文件、数据和checkpoint哈希可核查。

只有平均改善且楼层退化、种子稳定性都可接受，才支持继续扩大该方向。若训练损失下降但外层退化，保留负结果，先诊断共享任务数量和传播关系，不追着外层成绩调网络。外层报告不能证明统计显著，也不据一次实验声称新颖性。
