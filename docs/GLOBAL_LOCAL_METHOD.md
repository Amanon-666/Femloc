# 全局与局部关系共同定位

## 修改前的判断

目标楼层只开放 10 个位置、每点 3 次 RSSI。旧方法在源楼层训练编码器，然后由这 30 条扫描求一个从特征到坐标的线性映射。它能向锚点外推断，但一条映射要覆盖整层弯曲的无线关系。

简单的“相似锚点坐标加权平均”也不合适：输出必在锚点凸包内。对旧运行 seed 0 的固定划分，只用真实坐标计算这个几何下界，开发楼层 B0F3/B1F3/B2F4 的平均下界为 7.15/13.16/2.44，确认楼层 B0F2/B1F0/B2F3 为 2.91/10.78/7.94 个 UJI 投影坐标单位。纯加权平均不能消除该限制。

## 一个完整的方法思想

用同一个源端学得的 RSSI 编码器，构造两种扫描关系，再由目标楼层的 30 条标注扫描直接求坐标映射：

1. **全局线性关系**：中心化特征的内积允许向锚点区域外推断。
2. **局部无线关系**：特征距离的径向核允许附近锚点产生非线性修正。

两种核分别除以 Support 内平均对角值后等权相加。径向核的距离尺度取 Support 特征两两距离平方的中位数，不从目标 Query 的坐标或误差估计。两种核均在 Support 上中心化。令合成核矩阵为 `K`、Query 到 Support 的核为 `k(q,S)`、Support 坐标均值为 `ȳ`，则

`ŷ(q) = ȳ + k(q,S)(K + λI)⁻¹(Y−ȳ)`，

其中 `λ = 0.1 × mean(diag(K))`，沿用旧分支的相对正则强度。源端仍按 10 个 Support 位置与 10 个异位置 Query 构造 episode，训练编码器以降低未见位置坐标损失；目标端不做梯度更新。这不是 FeMLoc/MetaLoc 的原样复现。

## 固定比较与判据

与旧分支共用七个源楼层、三个开发楼层、三个探索性目标、10×3 标注预算、每个 seed 的具体划分、1500 源更新和开发集选轮规则。每个目标划分比较：

- 新方法；
- 同一新特征上的旧线性求解器，用来隔离局部关系的贡献；
- 随机特征上的新求解器、原始 RSSI 上的新求解器，用来隔离源训练的贡献；
- 原始 RSSI 岭回归、WKNN 两个简单参照。

已查看过这些目标楼层及官方 validation 结果，后续成绩只能称探索性证据。官方 validation 同时含时间、设备、用户和 AP 可见性变化；若该集退化，不把误差归给单一因素。只有在开发楼层及配对目标结果支持新方法时，才有理由继续研究 AP/设备稳健性；不根据某一目标楼层临时改核权重或正则系数。
