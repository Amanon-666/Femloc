# 用未见过的楼层转移选择训练长度

现有 AP 加权距离在七个旧楼层转移的**同转移新位置**验证上，1000→5000 源训练步持续变好，然而三个未见目标楼层的误差整体变坏。这不是目标端更新步数问题，而是验证单位错了：我们希望迁移到另一对楼层，验证时也必须留出整对楼层。

预先固定七个训练转移：B0F0→F1、B0F1→F2、B1F0→F1、B1F1→F2、B2F0→F1、B2F1→F2、B2F2→F3。对每个转移 `(L,U)`，完全留出上层 `U`；训练集移除以 `U` 为上层或下层的所有转移，避免它的标签借另一转移流入。用剩余旧转移按原模型和损失训练；每 100 步在 `(L,U)` 全部扫描上评估。七个留出转移等权平均误差最低的训练步数，为唯一的源端选定步数。候选固定 0、100、…、3000，同分取更早步。这个过程仅用随机种子 0，避免凭目标结果筛种子。

随后用全部七个源转移、全部源扫描分别训练 seeds 0/1/2 到该步数，不根据任何目标 Query 调整或选 seed。各 seed 的局部坐标残差参数仍按原规则只从旧楼层模拟 episode 选择。三个目标 manifest 原样，30 条 support、位置隔离 query；目标梯度步始终为 0。报告原 1000 步、5000 步和本次整转移验证选择的完整结果。若源留出转移和目标表现仍不一致，承认这套 AP 权重的源域代表性不足，停止进一步沿此路线调参。
