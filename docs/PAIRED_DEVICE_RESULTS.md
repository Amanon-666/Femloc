## 为什么受控采样仍不能代表目标任务

数据权限检查确认每个源 episode 的两台手机、30 条 Support、50 条 Query 和异位置隔离正确。但在七个源楼层各抽 100 个 episode 后，Query 到最近 Support 真实位置的平均距离通常从旧任务的 10–20 降为 7–12。例如 B1F2 从 20.32 降为 11.30，B2F0 从 13.53 降为 8.07，B2F1 从 13.71 降为 7.56。共同覆盖区域限制了可采的空间范围；此前固定目标划分的 B1F0、B2F3 对应距离约 18.48、13.68。

因此，训练任务同时改变了设备条件和空间跨度。其失败不能证明设备不变性无用，却足以说明“只按设备分割源数据”不是当前 UJI 跨楼层定位的有效训练方案。本文保留全部负结果，不继续按某个楼层调采样、核或正则；下一轮应先在任务层面明确源 episode 的位置跨度与目标锚点跨度如何同时对齐，再决定是否需要新的表示或算法。官方 validation 已多次被查看，后续同楼层结果均为探索性。
