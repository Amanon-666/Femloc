# 从旧楼层学习“什么样的信号变化仍表示同一位置”

## 为什么转向这一方法

第一版相邻楼层地图的直接匹配，在 B0F3/B1F3/B2F4 的固定少样本划分上为 7.46/15.18/14.74 米；10 个目标锚点的局部坐标残差只改善 0.13/0.20/0.36 米。全局平移会恶化三层。因此主要瓶颈不是在目标端多训练几步，也不是修正统一坐标偏差，而是跨楼层比较 RSSI 的距离本身。

我们保留“同栋下方紧邻楼层给出密集地图”这个已被数据支持的结构，重新学习指纹相似性。参考 LESS（IEEE TWC 2023）的“跨环境学习指纹间关系”思想；这里选择少参数、对 UJI 坐标直接监督的形式，不复现其深关系网络。RMDA（IMWUT 2023）支持利用已有精细 radio map 与目标少量测量，但其 floorplan 约束不能直接用于本数据。

## 模型与目标端权限

给定 source 楼层坐标 p 的平均指纹 u_p 和目标扫描 x，令每个 AP 的非负权重 `w_a=2*sigmoid(v_a)`，初值 w_a=1。跨楼层距离 `d_w(x,u_p)=sum_a w_a(x_a-u_{p,a})²`。为免最近邻在源地图上跳跃，用

`h_p(x)=softmax_p(-beta*d_w(x,u_p))`，`m_w(x)=sum_p h_p(x)*p`。

`beta=exp(b)`，初值 10；训练后限制在 [1,100]。权重只在旧楼层转移中学习。新楼层的 30 条坐标绝不用于更新权重，目标适应梯度步为 0。候选目标估计先以 m_w 为密集旧地图初值，再按 `docs/ADJACENT_MAP_METHOD.md` 的十锚点局部残差公式修正。局部修正的 `(l,lambda)` 重新在旧楼层任务上选择；不沿用为原距离选择的参数。

## 源楼层训练和参数选择

训练转移固定为 B0F0→F1、B0F1→F2、B1F0→F1、B1F1→F2、B2F0→F1、B2F1→F2、B2F2→F3，不使用最终三目标的坐标标签。每个高层按物理位置固定划出 80% 训练、20% 验证，避免同位置扫描跨两侧。每个训练步等概率选一对楼层，在其训练位置采 128 个扫描，最小化 `mean(||(m_w(x)-p)/100||²) + 0.001*mean((w-1)²)`。0.001 是对均匀 AP 权重的弱收缩，权重又受 [0,2] 硬约束，不做目标结果驱动搜索。

Adam 学习率 0.01、总步数 1000、每 100 步检查一次所有旧楼层转移的验证位置平均误差；取七个转移等权平均最小的旧楼层验证 checkpoint，同分取更早步。随机种子 0/1/2。这个模型容量只有 521 个数，不引入另一个 520→隐藏层的大网络。每个 seed 保存已选旧楼层验证步、AP 权重、beta；用对应 seed 的固定目标 manifest 评价。

局部残差的 9 个 `(l,lambda)` 候选和不校正候选继续只用旧楼层 20 个 episode/转移选择；每个 seed 独立选。评价时报告：固定欧氏最近源图、学习后源图、学习后+目标十锚点校正。不得根据三目标 Query 误差改训练步数、选 AP、选局部参数或选择某一个 seed。

## 可证伪性

若旧楼层验证没有改善或目标结果无一致收益，承认权重方法失败，不继续给个别目标楼层加阈值或例外。若大幅改善但只在已见的三个上出现，随后须用其他留出楼层验证泛化，不把这三个已探索的楼层称为独立外部验证。该方法不适用于新建筑没有相邻旧楼层图的情形。

## 训练收敛复核（源数据决定）

V1 预先固定的 1000 个**源训练**步后，三个随机种子的七对旧楼层验证误差在最后 100 步仍分别下降 0.09、0.07、0.13 米，所有最佳 checkpoint 都恰好落在上限 1000。为避免把训练不足误判为方法失败，另做一次 5000 个源步的收敛复核：每 100 步仍只看七对旧楼层的位置隔离验证误差，选其中最佳 checkpoint。目标楼层仍为 0 梯度步，目标 Query 不参与选择。将原始 1000 步结果完整保留，且不再依据目标分数追加训练轮次。
