# 第二轮：先审查核迁移假设

## 修改前的问题与判断路径

DKT迁移的是相似性函数，不是绝对坐标模型。输入维度相同并不保证各楼层的AP槽位组合服从可迁移的度量。先检查已有模型如何形成Support→Query的关联，不新增网络或目标训练。

按以下顺序比较解释：

1. **表示的跨空间失真**：共享MLP在已见楼层学会定位相关距离，但在新楼层把相近/不同位置的RSSI关系变坏。检查同一Support下深特征与原始RSSI核、最大核相关、后验对Support中心的偏移，以及与已见源楼层的差异。
2. **不确定性与实际误差脱节**：边际似然可能在源楼层学到很低噪声和过强相关，新楼层后验却过度外推。读取已训练的噪声/长度尺度，检查预测方差和误差，不据此直接添加裁剪或噪声下限。
3. **信息预算本身不足**：如果连原始RSSI邻近关系和Support位置覆盖都不足，单纯改网络无济于事。用Support中心预测作为信息不足参照，统计未见AP与Support/Query可见集合。
4. **训练尚未稳定**：5000是首轮工程预算，不是证明收敛。看源任务loss的分段趋势，不能因目标误差高就盲目延长训练。

本轮先读取已有权重、日志与任务做机制诊断。目标数据只用于描述已暴露结果，不能继续用三个最终目标挑选超参；如需比较方法，先从原10个源楼层留出开发环境，再做源任务内部验证。

真正的算法改动必须在此补充独立方法思想、推导与可证伪预期后才实现。若诊断不能区分解释，可以先保留现有模型，不能为了提交一个改动而添加处理。

## 诊断结果与本轮唯一修正

已有三seed的诊断见DKT_DIAGNOSTICS.md。源楼层DKT MDE 6.47m、原始RBF 18.84m；B2F4深特征最近邻18.46m劣于原始RSSI的16.80m。目标最大核相关约0.99，预测并未简单退回Support中心。源域未见AP仅占B2F4观测1.13%，数量证据不足以支撑“新AP是主因”。源训练loss从首1000步约0.77持续降至末1000步−0.52，既不证明收敛，也不证明跨楼层收益。

**明确缺口：只优化已见空间的边际似然、固定最后一步，没有独立新空间的模型选择。** 官方train.py分类入口已使用独立val任务保存best_model；此次把相同原则用于UJI回归。官方回归网络与GP数学保持不变。

方法思想：用源域内部未见环境评价“可迁移的相似性”，据此选择训练时长，避免把源任务拟合度直接当成泛化能力。

- 从原10个source中，按每建筑最高剩余楼层的确定性规则留出B0F2/B1F2/B2F3作development，另外7层训练。三个最终目标完全排除，不用于选择。
- 先做一个seed=0的有界开发运行；与最终运行一样，每个任务Support10×3，Query位置隔离。每开发楼层20个固定episode、同两算法配对。
- 预先观察0/500/1000/2000/5000/10000步。0为未训练参照，其余为5000初始预算两侧的阶段；10000为本轮2倍预算上限，不宣称是论文规定或保证收敛。
- 坐标尺度只从7个训练楼层拟合。选择规则是三个开发楼层episode平均MDE的等权平均，平局取较早步骤；DKT选择值控制后续训练预算。RBF曲线同时报告，不按最终目标选择。
- 此处只选择更新次数；不改输入、核、MLP、噪声约束、Support采样或目标更新规则。开发结束先解释曲线；不自动启动更多模型组合。

可证伪预期：如果源loss继续下降，而开发定位误差先降后升，说明固定末步的选择不合适；如果开发误差持续降低，只支持在该范围内继续训练，不能推断任意延长都有效；如果所有阶段均不优于原始RBF或随机深核，则预算选择不能解决表示迁移问题，应重新考虑表示假设，而非再加局部参数。

## 开发运行后的判断（修改下一轮配置之前）

预定检查点全部完成。等权开发MDE从46.920降至21.825、20.875、18.811、19.217、17.531m；按预定规则选10000步。5000步的暂时回升不能据此断言长期过拟合，10000步又改善。原始RBF在10000步为20.760m。支持的是“初始5000预算没有充分依据，源内部跨楼层选择仍有价值”，不是“早停一定更好”。

下一步只将最终源训练预算设为该已冻结的10000步，其他设置全部保持。使用原10source重新训练3个原seed、保持原目标manifest随机流，进行一次配对结果比较；不以最终目标误差决定再次延长。现有5000权重未保存optimizer状态，因此从相同初值重训，不能伪装成严格断点续训。

10000处于开发搜索上限，不能称最优或收敛；一次开发seed选择的不确定性保留。选择的是共享模型总更新次数，而不是每楼层相同epoch，7层开发训练与10层最终训练的每环境暴露次数不同，因此效果需要如实评价。

最终三个目标已在首轮及诊断中被观察过；本次预算选择不再读取它们，但不能称为从未看过的独立确认性测试。

## 等待配对结果期间的结构推导（候选，不直接实现）

GP后验的置信度以当前特征/核为真。即使新楼层特征关系错误，GP也不会自动知道；增大噪声只能改变相信观测的程度，不能恢复被编码器丢掉的区分信息。因此不能看到误差较大就临时加噪声下限。

官方正弦Feature是1→40→40；接到UJI后成为520→40→40，是一个显著信息瓶颈。源环境训练可能把某些AP方向压小，因为这些方向在源任务中没有定位价值；新楼层中这些方向却可能需要保留。该解释与“已见层收益大、某个新层最近邻关系变差”相容，但当前尚无因果证明。

比较两条本质路线：

1. **增加MLP宽度**：可减少压缩，却增加自由度，不能保证保留原始RSSI关系；仅靠宽度没有明确的几何保证。
2. **保留原始相似性通道**：令z(x)=[x,h(x)]，沿用RBF ExactGP。则距离平方为||x−x'||²+||h(x)−h(x')||²，归一化核相关等于两个RBF相关的乘积。深特征相同但原始RSSI不同的指纹，不再仅因特征碰撞就被判为高度相关；正定性由拼接特征上的RBF保证。无需特定楼层分支、手工邻接阈值或目标训练。

第二条有清楚的结构性含义，但也有明确失败条件：原始RSSI中的设备/遮挡噪声也会保留，可能阻断应当相似的扫描；输入和深特征尺度不同会影响两通道相对作用。不能把它描述为必然更好，也不能为了结果不断引入混合权重。若以后验证，应先在源内部开发环境比较，保留官方模型为基线，并明确称DKT扩展，不叫原样复现。

本轮先完成唯一的预算选择修正，不把该候选混入正在运行的配对实验。最终目标已被观察，后续改进结论必须承认探索性质。

## 外部资料交叉核对

[Ober等，UAI 2021](https://proceedings.mlr.press/v161/ober21a.html)给出了深核通过边际似然训练仍可能过拟合的实例。这支持保留独立任务验证，不足以证明本项目已经发生该机制。[Wilson等2025回应](https://arxiv.org/abs/2509.21228)指出，相关重参数化分析仍包含数据拟合项，不能据此声称复杂度惩罚必然主导并导致过度相关。因此本项目不采用“边际似然天然使核崩塌”的断言，也不凭这一争议直接改损失；保留官方目标，依靠源内部未见楼层证据区分优化与表示问题。

## 第二轮最终判断

相同seed与Support/Query下，10000步相对V1的平均误差变化：B0F3 +0.181m、B1F3 +1.904m、B2F4 +0.779m。预算选择的开发收益未传递到最终目标，不能称修复了定位性能。详见DKT_V2_COMPARISON.md。

本轮修复的是缺少独立环境选择这一流程问题；未证实训练不足是性能瓶颈。停止围绕更新次数继续局部修改，保留官方基线。下一次实质改动须围绕上述表示保真假设先完成论证，再在源开发环境验证，不继续根据已知目标误差挑参数。
