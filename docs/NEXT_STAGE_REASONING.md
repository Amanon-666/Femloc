# 下一步先解决什么

这轮方法将源训练、少量目标锚点和异位置预测放进同一目标，在 B0F2、B1F0 优于 WKNN；B2F3 内部评价基本打平，官方 validation 退化。下一轮的目标是解释并改善**跨楼层新锚点关系**的可迁移性，而不是为 B2F3 设一个专属系数。

## 两个结构性限制

1. 当前求解器假设整层楼存在一个从 128 维特征到二维相对坐标的**全局线性映射**。十个锚点若覆盖稀疏且无线空间弯曲，局部近邻法可能更准确。B2F3 内部评价中，本法 16.68、WKNN 16.53，至少没有证据表明全局映射已胜过局部关系。
2. `RSSI = f(位置, 设备, 时间, AP 状态, …)`。学得的特征既要保持位置差异，也要压低无关采集变化。七个源楼层的 489 个坐标位置中，有 383 个被至少两台手机观测过，允许构造“同位置、不同设备”的真实配对。但官方 B2F3 的 Phone 13 已在训练数据出现，仍比 WKNN 差 5.10；故**只处理未见手机**不是充分解释，时间和 AP 变化仍未被分离。

开发楼层的一个简单只读检查进一步暴露了特征风险：以“同位置不同手机”的一对扫描，比较“同手机最近的另一位置”扫描，训练特征前者距离更近的比例，B0F3 三种子只有 0.029/0.059/0.103；B1F3 为 0.697/0.576/0.576；B2F4 为 0.381/0.262/0.095。它说明有些楼层上设备差异可能压过近距离空间差异；最近另一位置的物理距离没有固定，因此这只是机制线索，不是定位性能指标。

## 候选的下一种方法思想

用**局部关系定位**替代整层的全局线性映射：源训练直接学习两次 RSSI 扫描的相似程度；到了新楼层，以目标 Support 坐标的加权平均预测 Query。Source episode 的 Support 和 Query 尽量由不同手机采集且位置互斥，使训练必须同时利用空间关系和跨设备稳定性。源数据审计表明七层各至少有两种手机分别覆盖 20 个以上可提供每点 3/5 条扫描的位置，因而这个任务可以构造。

形式上，对目标 Query `q` 与第 `i` 个 Support 扫描 `s_i`，学习正权重 `aθ(q,s_i)`，再预测 `ŷ_q = Σ_i aθ(q,s_i)y_i / Σ_i aθ(q,s_i)`；源端只对**未见位置**的 Query 坐标求损失。该方法是项目提出的待验证设计，和原始 WKNN 的关键差别应是**相似关系由其他楼层训练**，而不是人工固定 RSSI 欧氏距离。它可能改善弯曲的无线地图，也可能因 AP 身份变化而学不到可迁移相似性，不能预设收益。

先在完整留出的旧楼层评估它是否同时超过本版的全局求解器和 WKNN，再考虑正式使用目标楼层。官方 validation 已在本轮查看，后续对同三层反复试验只能报探索性结果；要检验确认性增益，需要冻结方法后使用另一批外部数据或新采集数据。RNP 的特殊散度目前没有解决上述两种结构性限制；若重新比较 RNP 与标准 VI，必须先按论文公式修正 VI 对照。
