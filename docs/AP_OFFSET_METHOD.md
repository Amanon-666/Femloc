# AP 偏移校准的跨楼层地图适应：事前方法与判据

## 研究问题与已知证据

已知相邻楼层的完整 radio map 有 60–113 个带坐标位置；新楼层只有 10 个标注位置、每点 3 次扫描。已有零标注旧地图比只用 10 个目标点重新学习整层坐标关系更强，但它在官方验证上的误差仍约 7–15 m。旧图候选召回诊断显示，在既定三个目标楼层，官方验证 Query 的旧图真位置附近（5 m 内）落入原始 RSSI 距离前 10 位的比例为 92.9%、85.1%、64.1%；前 20 位为 97.6%、85.1%、84.6%。这说明“候选位置存在”与“把它排到前面”是不同问题，尤其 B2F4 的前 10 候选仍经常缺少正确区域。

一个更具体的假设是：楼层改变后，同一 AP 的信号相对旧地图产生近似全楼层共同的偏移。只读诊断在七个历史相邻楼层转移中，每对随机抽 10 个新层位置×3 扫描，用已知 Support 坐标找到旧图最近位置；在两侧都有至少 3/5 次观测的 AP 上，Support 与未采集位置的 AP 平均偏移相关系数约 0.83–0.98。这个量只检验偏移可预测性，不证明定位一定改善；真实 Query 坐标只用于该诊断的事后计算。

## 一个完整方法

保留旧楼层每个坐标位置的全部扫描均值指纹 `u_j∈R^520` 和坐标 `p_j∈R²`。输入归一化固定为 `100→0`、其余 RSSI 使用 `clip((r+110)/110,0,1)`。旧图基线对新扫描 `x` 用全 AP 欧氏平方距离和事先由历史源转移选好的 `β=10` 软匹配：`m(x)=Σ_j softmax_j(-β ||x-u_j||²) p_j`。本分支不改变旧图构建或 `β`。

Support 扫描 `s_i` 带有真实坐标 `y_i`。对每个 Support 只用它的已知坐标找到旧图几何最近位置 `j(i)`；这一步不读取 Query 坐标。对 AP `a`，只在 Support 实际检测到 AP 且旧位置的平均指纹该 AP 大于零时比较信号，记录 `e_ia=x_ia-u_{j(i),a}`。令 `n_a` 是有效比较次数，估计全局偏移

`δ_a(λ)=Σ_i e_ia/(n_a+λ)`，当 `n_a=0` 时设 `δ_a=0`。

Query 扫描只对其实际检测到的 AP 做 `x'_a=x_a-δ_a`，未检测 AP 仍为零。允许校正后的连续特征略低于零或高于一，避免额外截断改变距离排序。把 `x'` 输入同一个 `m` 得到坐标。`λ` 是唯一新超参数，候选 `{0,3,10,30,100,∞}`；`∞` 等价于零标注旧图。此机制估计 RSSI 的 AP 级共同变化，直接改变旧图候选排序，不是预测坐标后的残差补丁；不训练新网络，目标梯度步数为零。

它依赖每个 AP 的偏移在已标注区域与未标注区域近似稳定。对局部遮挡、AP 消失、新增、不同设备造成的空间非均匀变化不作额外处理。官方验证与 Support 的时间、设备可能不同，故这项假设可能失效。

## 数据权限、选择、判据

历史选择仅用七对非目标相邻楼层转移。每对旧层全部 trainingData 建图，新层每次抽 10 个异位置 Support×3 扫描，其余位置为 Query；每对固定 20 个 episode。各候选 `λ` 在每对上的 Query 平均二维误差先求平均，再七对等权。对第 `d` 对的源端审计，`λ_d` 只能由其它六对选出，再评价 `d` 对；与同一 Query 的 `λ=∞` 配对。最终目标 `λ*` 由全部七对历史转移等权选择，绝不查看目标 Query 来改变它。

进入目标评价的事前门槛：七对留一转移评估的平均误差比旧图至少降低 1 m，且至少 5/7 对改善；另外，`λ*` 在这些历史新层的官方 validation 平均误差不得比零标注旧图更差。若未通过，记录负结果并停止目标评价，不继续叠加门控/局部残差/额外网络。

若通过：沿用 MetaLoc 分支已固定的 3 个目标×3 个 seed 的 row-id manifest。每组同一 Support、同日异位置 Query、官方 validation；目标标签只从 Support 读取。报告旧图、校准旧图、只用目标 Support 的 WKNN；分别给三目标与等权平均，不把不同 Query 协议的旧论文数字混排。Support 配对置乱可作机制审计：保持十个坐标及 30 条 RSSI 不变，只打乱位置对应后重估 `δ`，不能用于选参。

本轮目标楼层与官方 validation 已在先前分支多次观察，因此结果一律称探索性，不能当独立盲测。Query 与旧图的几何最近距离、前 M 候选最佳距离只作有标签诊断，不是可部署性能或理论下界。
