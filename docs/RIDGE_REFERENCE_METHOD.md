# 学表征，用少量标定一次求解坐标：V1

## 方法判断

目标是减少新楼层的标定位置，而不是重复证明预训练有效。主线接受用户建议，冻结为：历史楼层训练共享 RSSI 表征；到新楼层后，30 条有坐标扫描闭式拟合坐标映射；冻结表征，定位其余位置。

方法来源为 [R2-D2 原文](https://arxiv.org/abs/1805.08136)及[作者代码](https://github.com/bertinetto/r2d2)，核对版本 `fc0c13ec991bb9f84395cb12de57cb150ce76f8d`，核心文件 `fewshots/models/r2d2.py`、`adjust.py`。采用可微岭回归和源 Query 监督学习特征的思想，网络、任务、损失均改为 UJI 坐标回归；不声称完整复现原论文。原代码的分类输出校准不移植；原文附录 C 也未显示学习 λ 必然优于固定 λ，本版只在历史留出任务上选择它。

本轮先建立可信的闭式适应参考，不叠加 FEAT Transformer、动态图、重建损失、DKT GP 或目标微调。自己的地图研究提示，信号数值拟合变好不一定定位更好，因此直接以新位置定位损失训练表征，并保留完整旧地图作强对照。Support 校准表征是下一种可独立描述的假设，需以本轮结果和源域证据决定，而非预先加入。

## 数据、任务和权限

- 样本 `row_id` 为 CSV 表头后从 1 开始的行号。输入是固定 WAP001…WAP520；Building/Floor 只组织任务，不作为网络输入。
- 位置为同一楼层内完全相同的 `(LONGITUDE,LATITUDE)`。同位置、同 520 维 RSSI 的行归为同一观测组，采样候选只留该组第一行。
- 缺测值 `100` 编码为 `-110` 后，`x=clip((rssi+110)/110,0,1)`。这是一种固定输入编码，不将 `-110` 宣称为真实测量。AP 身份由固定列保留，没有动态图表示。
- 开发：目标 B0F3、B1F3、B2F4 完全不参与源训练；再留出历史开发楼层 B0F2、B1F2、B2F3，剩余 7 楼层训练。
- 最终：用全部 10 个非目标楼层重训，三个目标楼层只提供固定的 Support，其余标签只评价。源数据含同建筑其他楼层，因此这是跨楼层研究，不能称为整栋建筑留出。
- 源更新均匀选 4 个不同楼层。每楼层随机选 10 个至少有 3 组唯一扫描的位置，每点选 3 条作为 Support；再从其余至少有 5 组扫描的位置选 10 个，每点选 5 条作为 Query。两集合位置不重叠。
- 开发、最终目标 Support 只需每点至少 3 组扫描，抽 10 点×3 扫描；全部其他位置的唯一观测为 `unseen_position` Query。不再生成未使用的同位置 Query。
- 开发和最终分别保存具体 Support/Query `row_id` 的 manifest。同一阶段所有算法逐项使用相同索引。最终固定 5 组标定划分，配合 3 个训练种子；不再把训练随机性与只抽一次的 Support 混在一起。
- 官方 validation 在开发选择完成后才加载进行最终评价，全部原始 validation 行参与评分。开发阶段记录文件指纹，不读取其样本来拟合。
- 三个目标和开发层在历史研究中已经被查看，本轮是探索性比较。换分支、换划分不制造新的盲测。

## 求解公式

设 Support 有 `n=30`，编码器 `φθ: R^520→R^128` 为 `520→256→128`、每层 ReLU。令 `Hs=φθ(Xs)`；Query 特征为 `Hq=φθ(Xq)`。

先由 Support 计算：

\[
\mu_H=\frac1n\sum_i H_{s,i},\qquad
s_H=\sqrt{\frac1{nd}\sum_{i,j}(H_{s,ij}-\mu_{H,j})^2+10^{-6}},\quad d=128.
\]

\[
Z_s=(H_s-\mu_H)/s_H,\qquad Z_q=(H_q-\mu_H)/s_H.
\]

`sH` 是全特征共用的一个标量，**不是逐特征归一化**。只利用 Support 统计，Query 不改变它。

坐标原点 `o=mean(pSupport)` 在 float64 中计算；`Y=(p-o)/100m` 转 float32，避免大坐标直接进入网络。目标端一次求：

\[
G=Z_s Z_s^\top/d,\quad
A=(G+\lambda I_n)^{-1}(Y_s-\bar Y_s),\quad
\hat Y_q=\bar Y_s+(Z_q Z_s^\top/d)A.
\]

实现使用 `torch.linalg.solve`，不显式求逆。等价于有非惩罚截距的正则线性坐标映射；特征提取是非线性的，因此整套预测函数并非原始 RSSI 的线性模型。返回 `p̂=o+100m×Ŷ`。同一 Support 求解一次，任意 Query 批次共用该解，不用其他 Query 的信息。坐标整体平移会等量平移预测。

## 两种训练方式与四个对照

**Meta-Ridge**：每个源 episode 由 Support 求上面的解，Query 坐标只用于 `MSE(Ŷq,Yq)`；四楼层损失等权，梯度穿过求解器回到编码器。学习的是“30 条标定能帮助定位其余位置”的特征。

**Sup-Ridge**：相同初始编码器、相同源 episode 序列，训练时各源楼层有固定原点 `od=mean(该源楼层训练坐标)` 和独立线性头 `gd: R^128→R^2`。对相同 80 条有标签扫描做 `MSE(gd(φ(x)), (p-od)/100m)`；四楼层等权。不使用每 episode 变化的原点。目标端丢弃所有源头，用同一个 Support 岭回归适应。私有头使监督对照免于共享不同环境绝对坐标映射这一额外限制。

两训练方法均消耗每源任务相同的 80 条标签；Meta 用它们分别拟合和监督，Sup 全部直接监督。训练日志记录样本序列累计摘要及逐源楼层覆盖。开发方法同训练种子时，公共训练前缀应相同；不同选择步数后的总训练量可不同，必须报告。

**RI-Ridge**：相同架构、相同初始权重的随机编码器；**Raw-Ridge**：固定原始 RSSI 特征。两者也各自用开发层选择 λ。

**Support-WKNN**：只使用相同 30 条 Support，取欧氏 RSSI 距离最近 3 扫描，权重 `1/(distance+1e-8)`。

**Old-Map**：使用目标正下层全部唯一扫描，各已标定位置 RSSI 编码均值构成完整地图；最近 8 个原型按 `softmax(-10×平方RSSI距离)` 输出坐标。`k=8,β=10` 沿用既有历史地图选择。本方法具有同建筑、空间对齐的完整源地图信息；不是少标定方法同权限的泛化基线。保留它是为了判断部署有旧地图时训练的实际价值。原始完整目标地图不允许进入该对照。

## 选择和训练预算

- 所有工程参数在 `configs/ridge_reference.json`。Adam `lr=.001`；不新增学习率调度、目标梯度步或隐式数据清洗。
- Meta 在 λ `{.01,.1,1}`、开发种子 `{0,1}` 下分别训练至 2000 次源更新。记录 `0/250/500/1000/2000` 检查点。2000 是本轮有限源训练预算，用学习曲线判断，不等于保证充分训练。
- Sup 每开发种子训练一次相同 2000 步，每检查点评价上述三种目标求解 λ。Meta 与 Sup 分别选择开发三楼层等权 MDE 最小的 `(λ,step)`，不再强令 Sup 使用 Meta 的选择。Raw 与 RI 只选择 λ。
- 每个开发层用固定 5 组 Support 和全体异位置 Query。先平均每层 5 组、再三层等权、再平均两个训练种子。平分时选更少源步骤，再较小 λ。允许 0 步被选择，如训练没有帮助也如实保留。
- 冻结选择后，最终种子 `{0,1,2}` 分别用十源楼层训练到所选步数。不能根据三个目标成绩重新选择。

## 评价、记录与最小检查

主指标为 Query 扫描逐条二维欧氏误差的均值 MDE（米），同时记录 median/P90、nQuery、Support 拟合误差。分别报告 trainingData 的未标定位置和官方 validation。三目标对应三个建筑，汇总建筑等权，不能合并行数后使扫描多的楼层支配结果。

每个固定标定划分先平均 3 个训练种子；再报告 5 个标定划分的均值与样本标准差。配对比较先在相同划分/种子上相减，以负的 Meta−对照表示 Meta 更好。15 个组合不是 15 个独立场地。设备、用户和时间不作为网络输入，但这不等于其测量影响被消除。

目标适应为 0 个梯度步、一次闭式有监督求解，记录 Support 特征提取加线性求解的 GPU 同步耗时；不拿这个 0 直接对比 MAML 梯度步骤，也不声称原论文精确复现。

唯一前置检查入口 `scripts/check_ridge_reference.py`：双/原形式数值相等、求解梯度数值核验、坐标平移、逐条/批次 Query 一致、13 楼层真实数据的源/目标位置隔离、真实源网络单步梯度有限。检查不持久训练目标模型。

主入口 `env/bin/python -u -m scripts.run_ridge_reference --output outputs/ridge_reference_v1`。自动串行完成开发选择、最终训练、评价与 `docs/RIDGE_REFERENCE_RESULTS.md`。用日志、各阶段 `completed.json` 和实际进程判断完成，目录存在不能算完成；失败只报告，不盲目改参或重试。

## 对旧代码的核验结论

旧源 sampler 要求每个位置至少 8 组扫描。本数据中 B1F1 因此少 2 点、B1F2 少 3 点、B1F3 少 1 点、B2F2 少 1 点，其他 Support/Query 各角色可用点一致。问题真实但影响有限，不是此前整体效果的主要解释。旧文档逐维缩放说法与实际标量缩放不一致，本轮公式以实际算法为准。DKT 后续已有开发选择和 10000 步结果，附件中“仍只有 5000 步”不再成立。
