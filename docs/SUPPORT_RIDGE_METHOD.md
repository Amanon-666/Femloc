# 用少量新楼层锚点直接确定坐标映射

## 要回答的问题

旧楼层训练出的无线特征，能否帮助新楼层用 10 个已知位置定位未采集的位置？先前 MetaLoc 分支的目标梯度更新混合了整体坐标平移和局部关系学习。本分支把整体平移与小型坐标映射直接求出，只训练无线特征；它不是 FeMLoc 或 MetaLoc 的原样复现。

## 一个完整任务

一层楼是一项任务。源端每次从一层选 10 个 Support 位置，每点 3 条不同扫描；再选另外 10 个 Query 位置，每点 5 条扫描。目标端同样只开放 10×3 条已知扫描；训练集内其他位置及官方 validation 用于分别评价，Query 坐标均不进入映射求解。

编码器 `φθ` 为 `520→256→128`，输入沿用已有分支的固定 AP 槽位和 RSSI 变换。设 Support 特征矩阵为 `H`，坐标为 `Y`，Query 特征为 `h(q)`。先用 Support 均值对 `H,Y` 定中心，得到 `Hc,Yc`，再求

`A = (Hc Hcᵀ + λI)⁻¹Yc`，`ŷ(q) = mean(Y) + (h(q)−mean(H)) Hcᵀ A`。

`λ = 0.1 × trace(Hc Hcᵀ)/30`，使正则强度随特征尺度变化。`0.1` 是本版固定工程参数：平均特征特征值处相当于约 9% 的收缩；不按目标楼层结果调整。坐标先减去 Support 均值再除以 100，只为数值尺度；逆变换时把 Support 均值加回。网络训练只用 Query 坐标的均方误差。这样，已知坐标整体移动多少，预测也整体移动多少，而不必让网络从 RSSI 猜坐标原点。

这个方法借用[可微闭式求解元学习](https://arxiv.org/abs/1805.08136)的核心思路：源训练让特征适合少样本求解。它不使用该论文的原数据、原架构或报告数字。

## 楼层与选择

- 三个之前充分讨论过的楼层 B0F3/B1F3/B2F4 仅用于本方法的开发和训练轮数选择。
- B0F2/B1F0/B2F3 作为本版确认目标，从源训练、开发评估和模型选择中整层排除。余下 7 层是源训练楼层。
- 开发楼层各固定 3 个 Support/Query 划分，等权计算三层误差；在 `0,250,…,1500` 中选最低者。目标楼层各固定 5 个划分，三个种子共 15 次；不根据目标结果选择轮数或正则强度。
- 这些确认层曾在其它项目中作为源层出现，也影响了当前研究讨论；它们**不是从未接触过的数据**。本分支的训练流程没有使用它们，结果只称探索性确认。

## 必须同时比较的简单方法

四种方法使用精确相同的 Support 和 Query：源端训练特征＋岭回归；随机初始化特征＋岭回归；原始 520 维 RSSI＋岭回归；目标内三近邻 WKNN。后三者分别检验源训练、神经特征和复杂求解是否带来收益。训练数据内的异位置误差是主要机制结果；官方 validation 是混合时间、设备、用户和空间覆盖变化的次要结果。数值单位为 UJI 原始投影坐标单位，不声称已校正的实地米数。

若训练特征没有稳定超过原始 RSSI＋岭回归和 WKNN，不能把模型称作已解决跨楼层问题。若其在已知点拟合好但未见点仍差，应先检查跨楼层关系与空间覆盖，而不是叠加针对单个目标楼层的补丁。
