# 用少量已知位置检验旧图候选排序：事前方法

## 上一分支否定了什么

全楼层 AP 偏移在历史转移上确能降低按真实位置对齐后的信号误差，但不能稳定改善候选排序：七对留一转移只改善 0.795 m，较晚官方 validation 平均反而退化 0.069 m，未通过事前门槛。这不是“AP 偏移估计错误”单一问题，而是**信号重建与位置判别并非同一个目标**。

## 本分支唯一方法思想

保留上一分支的完整旧楼层图、`100→0` 归一化、`β=10` 软位置检索，以及由已知目标 Support 与旧图几何最近位置估计的每 AP 共同偏移 `δ_a(λ)`。本分支只改变“如何决定该偏移是否有助于定位”：不用历史楼层整体选一个 `λ`，也不以信号重建误差选择；在当前新楼层的十个已知位置上进行**逐位置留一**。

对每个候选 `λ∈{0,3,10,30,100,∞}`，十次把一个 Support 位置的三条扫描当验证，其余九位置的 27 条扫描估计 `δ(λ)`，用旧图预测被留位置的坐标。十个位置平均二维误差最小的候选作为该 episode 的 `λ*`；分数完全相同先选 `∞`，再选更强收缩。最后用完整 30 条 Support 重估 `δ(λ*)`，预测空间上未见过的 Query。目标梯度更新为 0。`∞` 等价于直接使用旧图，故方法能拒绝不可靠的偏移；是否能可靠拒绝由历史整层 Query 检验。

这里的留一位置交叉验证不是为修某一个楼层的误差临时加规则：它直接用少量新楼层标签估计“哪种信号对齐对位置排序有帮助”，与上一版最小化 AP 残差的目标不同。它不会学习 520 维可自由调节的目标权重，也不添加坐标输出残差。十个 Support 位置若覆盖不足或与 Query 的信号变化不同，选择同样会失效。

## 协议、事前门槛和停止条件

七对非目标相邻楼层历史转移复用上一分支保存的 20 组每对 episode，每组 10 个位置×3 条 Support，其余位置全部为 Query。旧图仍保留旧层全部训练扫描。对每组使用上述十位置交叉验证选择 `λ*`，与同 Query 的零标注旧图配对。七对平均改善至少 1 m、至少 5/7 对改善，且相同 Support 选出的方法在七个历史新层较晚官方 validation 等权平均不退化，才可在既定 B0F3/B1F3/B2F4 评价；不满足就记录负结果并停止。`β`、候选 `λ`、episode、门槛均在本次实验前固定。

若通过，读取原 MetaLoc 分支固定的三个目标×三个 seed 的 10×3 manifest，在同日异位置 Query 与较晚官方 validation 上同时报告旧图、Support 选择校准图、只用目标 Support 的 WKNN。WKNN 固定为归一化 RSSI 欧氏距离最近 3 条 Support 扫描，坐标按 `1/(距离+1e-6)` 加权。所有方法使用同一 Query。目标 Query 不能决定规则、早停、参数或是否换算法。再做保持十个坐标集合不变、仅置乱 RSSI/坐标配对的审计，区分真正使用位置对应和只利用总体信号分布。

所有目标楼层和官方 validation 已在旧研究中观察过，若进入目标评价仍只能称探索性。历史 source 官方 validation 仅作事前门槛，不反向调候选或规则。
