# SCM v1 机制审计：信号场与定位是否同向

## 动手前的判断

SCM v1 用 10 个目标位置各 3 条扫描，先估计目标层与相邻旧层在这些坐标的 520 维 RSSI 差，再用固定的空间核扩散到旧图位置，最后检索位置。这个方法暗含两个独立假设：

1. 10 个锚点的 RSSI 差能预测未采集位置的 RSSI 差；
2. 预测 RSSI 更准，会使无线最近邻的物理位置更准。

仅凭最终 MDE，无法区分哪条假设出了问题。SCM v2 的锚点留一选参和 v3 的分层场／删失匹配在历史源任务上都低于冻结 v1，因此本审计不加入新校正器，也不搜索参数。

## 固定数据与计算

只使用 UJI trainingData 中七对历史相邻楼层。每对用新随机种子 2718 抽 12 个 episode：目标上层 10 个不同位置各 3 次扫描为 Support，其余位置随机抽至多 300 条为 Query。所有对比共享同一 Query。旧图是下层全量 trainingData 按坐标求得的平均 520 维 RSSI。SCM v1 固定空间长度 60 m、噪声比 0.3、旧图几何近邻 3；定位固定 WKNN k=8、beta=10。这里参数来自之前对这些历史楼层的选择，不把本结果称为独立泛化验证。

对每条 Query，先在它的真实坐标处用旧图 3 个几何近邻预测 520 维 RSSI；SCM 再加入从 Support 插值得到的残差。对旧图和 SCM 分别记录全 520 维数值编码误差（沿用 v1 的 `100→−110`，不是物理 RSSI 测量误差），以及 Query 实际检出 AP 上的 RSSI 均方根误差。然后在完全相同的 Query 上记录旧图与 SCM 的二维定位平均误差。另按 Query 到最近 Support 的水平距离 `≤20 m`、`20–40 m`、`>40 m` 报告，使空间外推范围可见。信号场诊断使用 Query 坐标仅用于离线评价，定位器输入始终只有 Query RSSI，不能读 Query 坐标。

每对先平均 12 个 episode，再对七对等权平均；不以扫描条数加权选择胜者。本脚本只读训练数据，不读取三个最终目标楼层的 Query 或 validation 标签。

## 结果应怎样解释

- RSSI 误差和定位误差一起下降：两个假设在历史任务上都有支持，再检查官方验证中的采集条件变化。
- RSSI 误差下降但定位未下降：把信号场平方误差当成定位目标存在错位，应研究候选排序／位置损失；不继续给场插值加局部规则。
- RSSI 误差未下降但定位下降：当前校正更像改变候选排序，不能声称重建了目标无线场。
- 两者都未下降：10 锚点空间残差场的基本假设不足，应回到任务权限或换方法。

本审计不是新方法的正结果，也不能用这些已参与历史调参的楼层宣称外部泛化。

## 源端结果后的定向诊断（探索性）

源端实际观察到收益随 Query 与锚点距离增加而缩小。由此追加一个**固定方法的机制诊断**：对 B0F3/B1F3/B2F4 的三个既有 Support manifest，分别在同日异位置 Query 和官方 validation 上，按相同的距离分组，记录冻结 v1 的信号场 RMSE、定位 MDE 与到最近锚点距离。这个追加分析是在看过源端结果之后提出，且目标层在先前研究中已被多次查看，只能解释现象，不能作为调参或最终泛化检验。禁止依结果改动 SCM、WKNN 或阈值。

## 再次追加的输入假设审计（探索性）

目标结果显示信号场 RMSE 与定位可不一致；并且 SCM 与 v3 都把 `100` 作为无信号或删失。再对全部 trainingData 做一个不参与选参的描述性检查：同一 Building/Floor、经纬坐标、SpaceID、RelativePosition、UserID、PhoneID 下，按时间排序取相邻且相差不超过 10 秒的两次扫描；按第一次真实读到的 RSSI 强度分组，统计第二次为 `100` 的比例（并对交换顺序同样计数）。这只能检验 `100` 的观测行为，不能单独识别遮挡、姿态、随机扫描或设备因素，也不能用来优化既有目标分数。

## 候选排序核查（在看过目标 RMSE/MDE 分叉后追加）

B1F3 同日与 B2F4 较晚验证出现“信号 RMSE 降、MDE 升”。为了确认原因，不改算法，仅对每条 Query 找旧图中物理距离它最近的候选点，计算此候选在旧图指纹匹配与 SCM 场匹配中的 RSSI 距离名次；再记录它是否位于无线前 8、旧图最邻近坐标距离、到 Support 的距离。目标真坐标只用于这一离线排名审计。比较时仅用两张地图**共有的旧图坐标**，避免新增 Support 候选改变名次的分母；定位 MDE 另保留含 Support 的原 SCM 结果。结果只解释现象，不据此筛选候选或调整方法。
