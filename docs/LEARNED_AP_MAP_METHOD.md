# 用少量锚点更新地图，再学习 AP 的定位可靠度

2026-09-30。分支 `learned-ap-map` 从 SCM-T commit `e8e9a16` 建立；不继承其它分支未提交文件。

## 判断与本轮唯一假设

历史审计发现：RSSI 重建误差下降并不保证坐标误差下降。未检出也可能是扫描波动，不能机械当作一个固定低 RSSI。我们保留旧地图的密集坐标，把地图拆成检出概率与检出后的平均 RSSI，用稀疏锚点分别更新，再用历史跨楼层任务训练一个 AP 共享的小网络，学习这两种证据在定位时应有的可靠度。

可检验假设：**以最终坐标误差训练 AP 可靠度，比冻结同一双通道地图的可靠度能更有效地迁移。** 冻结双通道地图与学习双通道地图严格共享输入、地图更新、候选点和 Support；区别只有 163 个学习参数。这一对比单独回答“训练有没有收益”。SCM 与 SCM-T 另作现有强对照。

## 与文献的关系

- GUFU（IMWUT 2025）把 AP 与扫描的连接及 RSSI 放入图，在既有地图上学习更新。我们借鉴同一 AP 的关系要被明确保留，以及更新应作用于地图。这里的更新依据有坐标的 30 条锚点，不引入 GUFU 的无标签批次、AE、GraphSAGE 或新增 AP 链接预测，因此不是 GUFU 复现。原文：https://arxiv.org/html/2507.11038v1；官方代码：https://github.com/khchiuac/GUFU 。已核对 Zotero 条目 `363M7NHD` 及其原文附件 `TY7BNY8Z`。
- Physics-Aware Query-Conditioned Graph Attention Networks for Radio Map Estimation（2026 arXiv:2604.17414）在显式传统先验上学习残差，提示应保留现有地图；其 DeepMIMO、LoS 和 RSS 重建任务不能直接搬成 UJI 定位结论。本版训练目标选择坐标误差，而非引用其重建收益作为验收线。
- 纠正历史文档：FeMLoc 的 10:3 指楼层数，原文未明确目标端为 80% 数据。约 4/5 是本项目独立重实现的选择，不应归于作者。

作者仓库核对：固定 GUFU commit `e1f14c73165daceead6992b5047507704fb0d7c5`，实际阅读 `graph.py`、`sage_ve.py`、`util.py`、`pred.py`。直接复用 `util.py::rssi2weight` 到 `models/gufu_reference.py`，用于 AP–候选关系的强度特征。其余模块不能宣称直接运行：仓库清单未提供 `sage_ve.py` 导入的 `utils.py`/`config.py`；`LossFunc(torch.nn.Module, sigma)` 中 sigma 在此处未定义，训练调用另有 `simga` 拼写。原文与该快照的虚拟边实现（论文阈值、代码 top-K）也不同。新分支因此复用可用边权转换与显式 AP 关系思路，核心双通道定位器明确标为本项目实现，不把它冒充作者 GNN。

## 地图接口

每条扫描保留 520 个 WAP 的稳定对应关系。`100` 只产生检出标记 `z=0`；观测 RSSI 在 `z=1` 时才进入强度统计。

旧楼层按精确水平坐标聚合不同 `(RSSI,xy)` 观测组。对位置 j、AP a：

`P0[j,a] = 检出次数 / 扫描数`；`M0[j,a] = 只对检出值取平均`。

未检出单元的强度不是测量值：仅以该 AP 在旧图的全部检出均值作为条件强度先验；旧图从未见过的 AP 用 −90 dBm 初值。这些 AP 仍由其接近零的 P0 表示不可见。

目标 10 个 Support 坐标按每点 3 条不同指纹聚合，同样得到 `Ps,Ms`。用 3 个几何近邻、权重 `1/(d+1)`，在旧图上查询这些已知坐标的 P0/M0。

令 `K(A,B)=exp(-||A-B||²/(2*60²))`，`λ=.3`：

`P = clip(P0 + K(J,S)(K(S,S)+λI)^−1(Ps−P0(S)), .001, .999)`。

对 AP a，令 `Da` 为 Support 中检测到该 AP 的坐标集合，仅强度通道使用：

`M[:,a] = M0[:,a] + K(J,Da)(K(Da,Da)+λI)^−1(Ms[Da,a]−M0(Da,a))`。

`M` 限于 [−110,0]。未检出在概率通道提供约束，不被解释为 −110 dBm 的数值测量。强度通道不读取不存在的 RSSI。

两种通道均保存 GP 覆盖度 `C = diag(K_JS(K_SS+λI)^−1K_SJ)`，强度通道按 Da 单独算。保留旧图坐标及 10 个 Support 坐标作为候选（即使坐标重合也保留，沿用 SCM 的候选方式）。所有地图特征仅由旧图和 Support 构造。

## 学习与定位

每个候选–AP 关系有 7 个特征：旧检出率、新检出率、旧条件强度/新条件强度经 `(m+110)/110` 缩放、概率/强度覆盖度、该 AP 在 Support 坐标中被看到的比例。共享 `7→16→2` SiLU 网络输出 `h0,h1`：

`b = softplus(h0)/log(2)`；`σ = 4 + 12*softplus(h1)/log(2)`。

最终层零初始化；冻结网络的初始值是 `b=1,σ=16`。另有一个全局正温度 `T=softplus(t)/log(2)`，t 初值为 0。总参数 163 个。b/σ 是以定位损失拟合的判别参数，不宣称为设备物理参数。

Query 只提供 AP 检出 z 和实际检测到的 RSSI x。候选 j 分数：

`score[j] = Σa b[j,a]*(z[a]*log(P[j,a])+(1−z[a])*log(1−P[j,a])) − Σa:z[a]=1 ((x[a]−M[j,a])²/(2σ[j,a]²)+log(σ[j,a]))`。

AP 范围为旧图或 Support 曾见过的并集；Query-only AP 不扩充地图。归一化 `softmax(score/T)`，其候选坐标加权均值为输出。不使用 AP 身份 embedding；共同置换所有 AP 列时输出不变。矩阵实现等价于 AP 对候选位置的消息求和，无需图依赖库。

源训练每步抽一个历史转移 episode，更新上述网络及 T，损失是 Query 扫描的平均欧氏坐标误差；不另加 RSSI 重建损失。Adam，600 步，lr=.003，weight_decay=.001；预算预先冻结，100/300/600 步仅报告源端新 episode 曲线，不按最终 Query 选 checkpoint。目标端 0 梯度步，输入 Support 后只解小型线性方程并前向计算。

## 任务和比较

历史转移仍是 B0F0→F1、F1→F2；B1 同样两对；B2F0→F1、F1→F2、F2→F3。不训练 B0F3/B1F3/B2F4。每轮建筑等概率，建筑内转移等概率，转移内已存训练 episode 等概率。

每对 32 个训练、8 个源端曲线、20 个评价 episode，三者分别随机种子 410/510/610。抽样单独按转移重置。Support 为 10 个至少有 3 条不同指纹的位置；每处 3 条。Query 与 Support 坐标互斥，训练每 episode 至多 64 个 Query。所有 row ids 固定保存到输出 manifest，后续方法读取它们。

主结果按三折整栋建筑留出，每折拟合只用另外两栋的历史转移，各用 seed 0/1/2；评价在被留出建筑各转移的 20 个 episode 上成对运行。被留出建筑旧地图和 Support 仅是部署输入，不能反过来训练网络。曲线记录也只使用拟合建筑。固定 SCM 旧参数曾利用全部源建筑选择，故这里它是既有参考；双通道冻结/学习的对比不存在该差异。

方法：零标注旧图 WKNN；SCM v1；SCM-T；双通道冻结；双通道学习。全部共享评价 row ids；旧图与 SCM 分别使用既有 `k=1000/8,β=10`，SCM-T 固定 `σ=16,θ=−80`。冻结/学习双通道共享同一地图。

在主评价完成后，再用全部历史转移各训练三 seed，读取三个既有目标的固定 10×3 manifest 做探索性附录。官方 validation 只在权重冻结后评价。每层并报扫描等权 MDE、位置等权 MDE；先楼层平均再建筑等权汇总。扫描均值与位置均值不得混成一项。

## 限制与本轮停止条件

只有三个建筑、七对相关历史转移；现有官方 validation 与目标楼层均已反复查看，不能称盲测。设备/用户/时间影响仍混合。方法需要相邻旧地图及对齐坐标，不等于未知整栋建筑的无地图定位。

若学习只改善源端拟合而在整栋留出无收益，本轮如实记录，停止追加网络模块。若检出/强度双通道本身不如 SCM-T，也保存负结果。主要结论由冻结/学习的配对差决定，而非目标最好数字。
