# UJI RSS residual modulation, 2026-10-14, before target performance

Question: can explicit Support spatial-response statistics and an AP-shared monotone map improve a strong raw RSS GP in an unseen building? This first run compares practical performance only. At the user's request it omits geometry/remapping ablations; no gain can yet be attributed specifically to geometry or individual AP selection.

Allowed information: two source buildings for training/development; target Support coordinates and RSS; individual target Query RSS only for prediction. No target old map, AP location, floor plan, Query coordinates or Query-fitted normalization. Reuse the exact frozen ADKF-IFT position-isolated manifests for one seed, first five draws, K=5/10/20, three distinct fingerprints per physical Support position. Thirteen target floors, three building leave-out folds. Internal and official later-date Query splits are separately reported, same Query per draw for all K. Physical sampling still determines coverage; repeated scans do not add locations. Official results mix time/device change with location generalization.

Base GP: raw_source parameters from the previous frozen ADKF comparison, source-development checkpoint for development, full-source checkpoint for final retraining/inference. Both coordinate GPs' amplitude, lengthscale and noise are frozen. They contain no target learning; initial modulation predictions are bitwise identical to this raw baseline. The old source model uses joint marginal likelihood; this experiment trains only modulation via conditional Query MSE. MSE matches the deployment prediction path, but is not the Euclidean MDE evaluation loss and does not calibrate predictive variance.

RSS encoding is unchanged: raw CSV value 100 is not observed; it maps to 0. Actual RSS maps to (RSS+105)/105; UJI's weakest observation is -104, not -90/-95. Missing RSS is excluded from physical response/noise statistics. No target per-column standardization, which would destroy identity with the raw GP.

Statistics: aggregate repeated scans at unique Support positions separately per AP. Visible count is the number of physical positions with at least one detection, not scan count. Eight inputs: visible-position fraction; observed within-position SD times fixed factor10; fraction of positions with repeat detections (so an unmeasurable variance is not described as stable); in-sample ridge R2; ridge slope norm; fewer-than-three-position indicator; observed-position geometry smallest/largest covariance eigenvalue ratio; observed mean normalized RSS. A centered linear RSS response fits only detected position means, with average covariance and a priori slope ridge .1 in source-normalized coordinate units. Fewer than three positions sets slope and R2 to zero, with a visible insufficiency flag; collinear geometry is disclosed by its rank ratio. These are descriptive proxies, not recovered AP positions or propagation exponents. In-sample R2 can be optimistic, especially for three points; no claim of held-out AP reliability.

Map: a shared 8->16(tanh)->4 network gives four bounded log slopes tanh(output). Last affine weights/bias initialize zero. Piecewise intervals at0/.25/.5/.75/1 have positive slopes exp(log slope), and phi(0)=0. Implement phi=x+sum_j(exp(log slope_j)-1)*clip(x-j/4,0,.25), hence exact identity at initialization. APs never visible in Support remain identity, including Query-only APs: no spatial response is inferred for them. All AP slots participate in the same raw distance sum, preserving baseline identity. An arbitrary AP-common renaming does not alter distances. A task-constant additive AP offset cancels in RBF distances and is not introduced as an unidentifiable parameter; gain is already represented by the slopes, avoiding redundant alpha and delta parameters. Coordinate translation is invariant; source rotation/reflection trains generalization, but rotation invariance of the full statistics-conditioned model is not claimed.

RBF is applied to the resulting per-sample vector, so for a fixed Support it is symmetric/PSD. It is a Support-label-conditioned predictive model, not an unconditional GP prior whose kernel is independent of responses. Training excludes Query from descriptors. Support and Query labels in source episodes are centered by Support only, scaled from other-building source coordinates only. Source query MSE differentiates through both Support/Query feature transformations and dense GP posterior solve. No target optimizer or gradient update, and no cross-task learned state.

Zero last layer blocks hidden-layer gradients at the first update but leaves final-layer gradients active. The source-only preflight explicitly checks final gradients at initialization and hidden gradients after one update; no multiplicative zero gate is placed before another zero final layer. Positive bounded slopes preserve observed signal order and avoid collapse, but do not prove any monotonic physical distance relationship. Identity initialization does not guarantee performance after learning; include zero-step source candidate and retain raw GP comparator. Fixed base lengthscale prevents direct GP-scale optimization from bypassing the modulation, but a shared neural gain can still act as global distance adjustment; no AP-specific mechanism claim without later ablations.

Training: one source floor episode/update, K uniform5/10/20, three distinct scans/position,30 Query positions with one scan each, random source-coordinate rotation/reflection, Adam1e-3. Source development uses the highest floor in each permitted building, checkpoint candidates0/300/1000; select by mean MDE over both Query splits, K and two source anchor draws. Reset modulation to same-seed identity, refit selected step count on all allowed source floors using the full-source base GP. WKNN aggregates Support scans to one fingerprint/physical anchor and uses raw normalized RSS distances; nearest count1/3/5 and inverse-distance power1/2 selected only on the same source development set. No target-guided retry/expansion.

Boundaries: empty Support does not define coordinate center and is outside this K>=5 experiment; one anchor/constant coordinate gives zero centered label and constant coordinate prediction; weak/collinear Support cannot identify unseen direction; all-missing or constant APs have no measured gradient; Query-only AP stays raw rather than receiving invented geometry. Duplicate/conflicting fingerprints, missing APs, noise, and sparse exterior Query remain unresolved information limits. Whole-floor coverage cannot be created by monotone transforms. With no target labels used for selection, source improvement may transfer poorly. One seed is a fast first performance result, not a final multi-seed conclusion.

Order: forward derivation recorded here; implement; source-only identity/gradient/ordering/permutation/translation/constant-label checks; reverse review; freeze commit before formal run; then retain complete target results regardless of scores. No ablation experiments are run. Use existing environment, CPU2 threads, without interrupting other jobs.
